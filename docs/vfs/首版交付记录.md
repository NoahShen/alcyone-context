## 2. 已交付核心能力概览

VFS 首版作为嵌入式 Agent-native VFS Library，提供以下已闭环能力：

1. **统一逻辑寻址与路由**：
   - 统一使用 `alcyone://<namespace>/<path>` 逻辑 URI 寻址；
   - 支持多后端挂载路由，按最长前缀逻辑路径匹配（`VfsMountConfig`）。
2. **多存储后端支持**：
   - 本地文件系统（`MountBackend.LocalFs`）；
   - WebDAV 远程存储（`MountBackend.WebDav`，支持基础身份认证与 TLS）。
3. **核心文件与目录操作**：
   - 读取（全量读取 `read`、分块流式安全读取 `openReadStream().use { ... }`、支持读取限额与安全关闭）；
   - 写入（`CREATE_NEW`、`REPLACE_EXISTING`、`UPSERT` 三种模式，保证底层与元数据状态一致）；
   - 状态查询与目录列出（`stat` 懒注册 Node ID、`getNode` 查询已登记节点、`list` 混合物理存在与逻辑节点）；
   - 移动（同 Mount 原生移动、跨 Mount 编排“读源-写目标-确认-删源-迁移节点”、保证 Node ID 连续连续性）；
   - 删除（文件删除与目录递归删除，逻辑标记清理与事件触发）。
4. **节点身份与元数据管理**：
   - 基于 UUIDv7 的稳定 Node ID；移动/跨后端移动保持身份不变更；
   - 支持元数据（`NodeMetadata`）整体替换与时间戳同步更新。
5. **事件与通知机制**：
   - 事务提交后进程内异步分发（`FILE_CREATED`、`FILE_WRITTEN`、`FILE_MOVED`、`FILE_DELETED`、`DIRECTORY_MOVED`、`DIRECTORY_DELETED`、`METADATA_UPDATED`）；
   - 消费者（Consumer）异常分层隔离，第三方异常不反向破坏操作结果与分发循环。
6. **生命周期与状态持久化**：
   - 控制平面基于 SQLite 单连接严格事务（`BEGIN IMMEDIATE`）；
   - 优雅关闭（`close` 协调等待 in-flight 任务完成、释放 Operator 与数据库句柄、取消分发协程）；
   - 正常关闭后支持原路径重新打开并保证节点身份一致性。

## 3. 支持边界与已接受限制

为确保接入方在合理假设下设计系统架构，明确以下已接受的设计与运行边界：

1. **平台支持边界（Mac-Only 承诺）**：
   - 仅在 **macOS arm64**（Apple Silicon）完成实机完整测试与验证；
   - Linux (x64 / arm64) 构建配置已保留但当前未做实机实跑验证，不作正式支持承诺；
   - 本地打包发布的 Mac 产物中，OpenDAL 的 native classifier 固定为 `osx-aarch_64`，跨架构机器直接引用会因缺少 native binary 失败。
2. **网络等待与阻塞边界（方案④）**：
   - 底层 JNI/Rust 原生网络请求与 `close()` 不提供最长耗时保证；
   - 当遇到网络挂起或远端无响应时，禁止外部宿主线程强杀（强杀可能导致 JVM 进程崩溃或 JNI 内存泄漏），需等待原生层完成或超时。
3. **状态库与事务边界**：
   - SQLite 状态库仅支持**正常关闭后的离线冷备份与原挂载路径恢复**；
   - 不承诺在线热快照、崩溃自动恢复（Crash Recovery）或跨后端物理操作与 SQLite 的分布式事务原子回滚；
   - 跨后端移动过程中若目标写入成功但源删除失败，系统保留两端物理文件与当前逻辑映射，报告 `PARTIAL` 或 `UNKNOWN`，**禁止上层或底层盲目静默清理源端**，应由人工/运维排查现场。
4. **安全与权限边界**：
   - VFS 无内置 Agent 身份体系，亦无 ACL 访问控制权限模型；
   - Agent 的工作目录范围隔离与多租户权限校验必须由上层 **Context System** 在调用 VFS 之前约定和实施。
5. **事件边界**：
   - 事件仅保证进程内异步分发与基础持久化日记，不包含分布式消息重试、持久化消费位点与重启重放能力（规划于后续 E05 扩展）。

## 4. 接入指引与验证入口

### 4.1 接入配置

外部消费工程声明本地仓库与依赖：
```kotlin
// settings.gradle.kts 或 build.gradle.kts
repositories {
    maven {
        name = "projectLocal"
        url = uri("/absolute/path/to/alcyone-context/.local/sdk-repository")
        content {
            includeGroup("com.github.noahshen.alcyone")
        }
    }
    mavenCentral {
        content {
            excludeGroup("com.github.noahshen.alcyone")
        }
    }
}

dependencies {
    implementation("com.github.noahshen.alcyone:alcyone-vfs-runtime:0.1.0-SNAPSHOT")
    implementation("org.slf4j:slf4j-simple:2.0.17")
}
```

### 4.2 可复现验证命令

在本项目根目录下依次运行以下三项独立闭环验证：

```bash
# 1. 常规测试套件回归（含各模块单元测试与集成测试，基线 752 例）
./scripts/check

# 2. 真实 WebDAV 服务集成测试（启动临时 Python WsgiDAV 服务，基线 43 例）
./scripts/webdav-check

# 3. SDK 本地打包与独立最小 JVM 消费工程端到端验证
./scripts/t31-consumer-check
```
