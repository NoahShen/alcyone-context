## 1. 目标

实现 `ExtractionRunner` 的真实业务闭环：

```text
Scheduler → ExtractionRunner.execute(sessionKey)
  → PreExtractionContextBuilder.build（CT10）
  → LlmClient.complete（事务外）
  → ExtractionResultValidator（整批严格校验）
  → database.write（Raw insert + organization_pending + Target complete 原子提交）
  → COMMIT 后 Organization Immediate 通知（新增 Raw > 0）
```

- 单 Turn 确定性超预算：仅锚点 `pending→failed`，继续寻找下一条 Pending；
- 固定开销/配置错误、LLM/网络/非法响应：不写库、不误标 failed；
- 零记忆 `{"memories":[]}` 是成功，原子完成全部 Target；
- 不实现 Organization 治理、CT12 评测。
