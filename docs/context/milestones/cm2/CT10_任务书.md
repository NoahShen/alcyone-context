## 1. 目标

在同一个短 SQLite `ReadContext` 快照内，从指定 Session 的最新 pending Turn 出发，选择受完整 LLM 请求 Token 预算约束的**连续会话窗口**，返回不可变 `ExtractionContext`：

- Snapshot 时 pending 的 Turn 是 Target；complete/failed 仅作 History；
- 超预算按 `N = max(1, floor(N/2))` 保持锚点重读，首次满足即固定；
- 只有 `N=1` 仍确定性超预算才进入「该锚点不可处理」语义（Builder 不写库，交由 CT11）；
- 无 pending 返回空结果；不调用 LLM；
- 固定 Prompt/Schema/输出预留本身超容量属配置/固定开销错误，不得误标 Turn failed。
