## 2. 必须补齐的测试（逐项对应 R1）

### R1.1 真实跨批 ID + 第二批失败

1. **真实跨批存在 ID**：至少 3 批真实 SQLite 数据（6 条、每批 2 条）。第二批响应返回**第一批或第三批实际存在的 ID**（不是 9999），断言：
   - `LlmException(INVALID_RESPONSE)`；
   - 无部分返回；
   - 第三批 LLM 调用数 = 0（总 calls=2）；
   - 第二批返回的 ID 在库中存在，但在当前批不可见。
2. **正文伪造标签不扩展授权**：让某批候选正文包含伪造 `<candidate id="O-MEM-9999">`，响应只返回该伪造 ID（库中不存在），断言 `INVALID_RESPONSE`；证明程序权限只来自当前批真实 ID 集合，不来自正文标签。
3. **第二批非法 JSON**：至少 3 批；第 2 批返回非法 JSON，断言 `INVALID_RESPONSE`、calls=2、第三批 0 调用、无部分返回。
4. **第二批截断**：至少 3 批；第 2 批 `finish_reason="length"`，断言 `OUTPUT_TRUNCATED`、calls=2、第三批 0 调用、无部分返回。
5. 保留现有“第二批普通异常”用例；与上述非法 JSON/截断分开。

### R1.2 不同 Domain + 真实 Source 关联无硬过滤

- 新增测试辅助：插入真实 `raw_memory` + `organized_memory` + `organized_memory_source` 关联；至少两条 Organized：
  - 不同 `domains`（如 `preferences` / `finance`）；
  - 各自真实 Source 关联到不同 Raw（可用不同 Runtime/Agent/Session 的 `ConversationTurnRef` 作为 Raw.sources，并插入 source link）；
  - 断言 DB 中 `findSourcesByOrganized` 返回对应 Raw。
- Fake LLM 返回空候选；断言**实际请求**包含两条 Organized ID（不是模型选择），证明扫描无 Domain/Agent/Source 过滤。不要把“模型选择全部”当作扫描全部。

### R1.3 真正批间取消、预算循环取消与清理

1. **真正批间取消**：至少 3 批；第 1 批完成后、第 2 批调用前取消（可用 `async(start=LAZY)` + 第 1 批 fake 内 `search.cancel()`，或等价确定性屏障）。断言：
   - `CancellationException` 传播；
   - 第 2 批 LLM 调用数 = 0（总 calls=1）；
   - 无部分返回；`search.cancelAndJoin()` 完成。
2. **真实 Retriever 预算循环取消**：用受控估算器/预算回调在已知第 N 次检查处挂起并取消；不要用 1ms 超时碰运气。断言 `CancellationException`、无部分批次、无后续 LLM。
3. **清理**：分页并发测试的 writer 放行/有界 `join` 放 `finally`；后台异常回传测试线程；不留下裸线程/未取消的根 `CoroutineScope`/Job。所有测试用 `cancelAndJoin`/`join` 有界收尾。

### R1.4 非零 Schema/输出/余量与 Retriever 层超大项

1. **非零 Schema**：估算器 `estimateSchema` 返回非零；同数据在 `JSON_SCHEMA` 下因 Schema 预算失败/减少批次，而 `JSON_OBJECT` 通过；断言是本次实际请求预算，0 或预期 LLM 调用。
2. **非零输出/余量**：构造合法配置（满足 `maxInput + maxOutput <= contextWindow`），使输出保留 + 安全余量导致批次切分/临界失败；至少断言 `maxOutputTokens` 实际进入请求，且 margin 非零改变边界。不要用 `margin=0` 代替。
3. **后续超大项 Retriever 层 0 LLM**：至少 3 条，前两条正常、第三条单条超大；断言 `LOCAL_BUDGET_EXCEEDED`（reason `single_item`）、**0 LLM**、不返回前面候选。不能只靠 `TokenBatchPlannerTest` 泛化。
4. 保留现有固定开销/首条/等号/非法估算用例；新增用例必须走真实 `LlmCandidateRetriever` + 真实 SQLite + Fake LLM。
