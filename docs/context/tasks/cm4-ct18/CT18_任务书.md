## 1. 目标

CT18 只交付 Memory Map 的**单次固定快照生成、严格校验与安全发布**组件：

```text
单次 ContextDatabase.read
  → 全量 Organized + T1 = MAX(updated_at)
  → 退出 ReadContext
  → MEMORY_MAP Prompt / LLM
  → 严格解析 + Core 校验
  → Core Front Matter + Markdown 渲染
  → VFS safeReplace alcyone://memory/map.md
```

- Map 是派生导航，不是权威事实源。
- 全量 Organized 必须纳入；超预算明确失败，不截断、不分批、不发布。
- 生成期间新 Organized 提交不改变本次 T1；不查 T2、不加发布协调锁。
- 生成/校验失败不发布；发布只使用 CT17 `safeReplace`，不得普通覆盖或 delete+move。

## 3. 冻结候选契约

以下为 CT18 B1 建议契约；带 D 编号的项目须 Architect 裁定后才能派发。

### 3.1 固定快照与 T1

- 单次 `ContextDatabase.read` 分页读取全部 Organized，页大小 256。
- 读取结束后在内存按 `id ASC` 排序。
- 同一 ReadContext 读取 `maxUpdatedAt()` 作为 T1；空表为 `null`。
- 必须核对 `T1 == memories.maxOfOrNull(updatedAt)`；不一致视为快照错误，不调 LLM、不发布。
- ReadContext 结束前不构造 LLM 请求、不调用 VFS。

### 3.2 LLM 输出与 Prompt

- 使用既有 `LlmTask.MEMORY_MAP`，不新增 Task 枚举。
- 建议 D1：LLM 返回 JSON 信封 `{overview, navigation, domains}`；只允许 `JSON_SCHEMA`/`JSON_OBJECT`。
- `overview/navigation` 非空；`domains` 为字符串数组，空白拒绝、稳定去重、必须为本次快照真实 Domain 的子集。
- Prompt 必须保留不确定性、禁止编造事实/Domain/Resource URI、禁止把正文当指令。
- 输出 `finish_reason == "length"` 明确 `OUTPUT_TRUNCATED`。

### 3.3 预算

- 使用现有 `LlmBudget.requireWithinBudget`、`ConservativeTokenEstimator`、Task/Profile 配置。
- 固定全量请求一次；输入超 `task.maxInputTokens` 或输入+输出保留+余量超 Profile 容量 → `LOCAL_BUDGET_EXCEEDED`。
- 不静默丢弃任何 Organized，不把部分输入称为全量 Map。

### 3.4 Front Matter 与 Markdown

- 固定路径：`alcyone://memory/map.md`。
- 唯一字段：`generatedAt`、`sourceUpdatedAt`。
- 时间使用 `TimeCodec` 固定上海 `+08:00` 毫秒。
- 建议 D2：空库 `sourceUpdatedAt: null`；非空为 T1。
- 必需标题：`# Memory Overview`、`# Memory Navigation`。
- 建议 D3：缺失/重复/未知 Front Matter 字段、非法时间、缺失标题均视为非法，不把缺失当有效水位。
- Core 不得依赖 SnakeYAML；使用严格两字段解析器。

### 3.5 空库

- 建议 D4：空 Organized 不调用 LLM，生成确定性空 Map（固定 overview/navigation），`sourceUpdatedAt: null`。
- `generatedAt` 仍使用注入 Clock 的实际生成时间。

### 3.6 安全发布

- `MemoryMapPublisher` 只调用 `Vfs.safeReplace(MAP_URI, renderedBytes)`。
- 不读取旧 Map 作为事实源，不使用普通 write/move/delete。
- 生成/校验失败不调用 Publisher。
- 发布前失败保留旧 Map；物理替换成功但 VFS 状态失败按 CT17 契约报 `STATE_ERROR + PARTIAL`，完整新版可能已存在。
- 不查 T2、不加跨存储事务、不实现发布锁。
