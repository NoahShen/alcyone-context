## 2. 实现范围

### 2.1 Snapshot / T1

- 单次 `ContextDatabase.read`，默认 256 条/页读取全量 Organized。
- 同 ReadContext 读取 `MAX(updated_at)=T1`，并校验集合 MAX 一致。
- 退出 ReadContext 后按 ID ASC 排序并调用 LLM。
- 生成期新写入不改变本次 Snapshot/T1；不查 T2、无发布锁。

### 2.2 Prompt / LLM

- 使用 `LlmTask.MEMORY_MAP`，Prompt/Schema v1 资源。
- JSON 输出 `{overview,navigation,domains}`；仅 JSON_SCHEMA/JSON_OBJECT。
- 全量一次请求；预算超限 `LOCAL_BUDGET_EXCEEDED`，0 LLM。
- `finish_reason=length` → `OUTPUT_TRUNCATED`。
- 空库 0 LLM，确定性空 Map，`sourceUpdatedAt:null`。

### 2.3 Parser / Validator / Renderer

- Parser 严格 JSON object；未知/缺失/类型错误/围栏/截断拒绝。
- B1-R1 增加根对象重复 key 扫描；重复 `overview/navigation/domains` 与转义等价 key 均 `INVALID_RESPONSE`。
- Validator 要求 Overview/Navigation 非空、真实 Domain 子集、LF 与保留边界安全。
- Renderer 生成两键 Front Matter、固定标题、上海 `+08:00` 毫秒时间、确定性真实 Domain 列表。
- Front Matter Parser 拒绝缺失/重复/未知键、非法时间、CRLF、非法 UTF-8、标题/Domain 结构错误。

### 2.4 Publisher / Service

- 固定 URI `alcyone://memory/map.md`。
- 唯一生产写调用为 `Vfs.safeReplace`；无普通 write/move/delete 或物理写降级。
- 生成/校验失败 Service 0 发布。
- 提交前失败旧 Map 保留；`STATE_ERROR + PARTIAL` 原样传播，完整新版可能已存在。
- 未接 Factory/Impl/Config/Cron/Bootstrap/Search/Get/HTTP。
