## 1. 任务

只实现 CT18 的 Memory Map 单次固定快照生成、严格校验与安全发布组件：

```text
ContextDatabase.read Snapshot + T1
  → MEMORY_MAP LLM 一次全量请求
  → 严格 JSON Parser / Core Validator / Renderer
  → VFS safeReplace alcyone://memory/map.md
```

不接 Factory/Impl，不实现刷新 Worker/Cron/Bootstrap/Search/Get/HTTP。

## 2. 冻结实现要求

### 2.1 Snapshot

- 单次 `database.read`，256 条/页，读取全部 Organized。
- 同一 ReadContext 读取 `maxUpdatedAt()` 为 T1。
- 校验 T1 与集合 `maxOfOrNull(updatedAt)` 一致；空表均 null。
- 退出 ReadContext 后才按 `id ASC` 排序、构造 Prompt、调 LLM。
- 分页偏移受检，长预算/分页循环响应取消。

### 2.2 Prompt / LLM

- 复用 `LlmTask.MEMORY_MAP`，不新增枚举。
- 必须使用 Core 资源 `memory-map-v1.md` / `memory-map-schema-v1.json`。
- 建议 D1 输出 JSON `{overview,navigation,domains}`，仅允许 JSON_SCHEMA/JSON_OBJECT。
- 缺 Task/Profile 或非 JSON 模式 → `ContextConfigException(INVALID_CONFIG)`。
- 全量请求一次；使用 `LlmBudget.requireWithinBudget`。
- `finish_reason=length` → `LlmException(OUTPUT_TRUNCATED)`。
- 不得分批、截断或把部分输入当全量。

### 2.3 Parser / Validator

- 严格 JSON object，无围栏/前后文本/未知字段。
- `overview/navigation` 非空；`domains` 为字符串数组。
- Domain 空白拒绝、稳定去重、必须属于本次快照真实 Domain 集合。
- Parser/Validator 非法统一 `LlmException(INVALID_RESPONSE)`（建议 D10）。
- Validator 检查渲染必需结构/长度；不静默截断。

### 2.4 Front Matter / Renderer

- 固定 Markdown：

```markdown
---
generatedAt: <上海 +08:00 毫秒>
sourceUpdatedAt: <上海 +08:00 毫秒 | null>
---

# Memory Overview

...

# Memory Navigation

...
```

- Front Matter 仅 `generatedAt/sourceUpdatedAt` 两键。
- 空库 `sourceUpdatedAt: null`（建议 D2/D4）。
- 严格 parser：缺失/重复/未知字段、非法时间拒绝；不使用 SnakeYAML。
- 建议 D5：Renderer 在 Navigation 中确定性列出本次真实 Domain，不编造。

### 2.5 Publisher / Service

- 固定 URI：`alcyone://memory/map.md`。
- 只调用 `Vfs.safeReplace`，禁止普通 write/move/delete。
- 生成/校验失败时 Publisher 0 调用。
- 发布前失败旧 Map 保留；状态失败按 CT17 `STATE_ERROR + PARTIAL` 原样传播。
- 不读取旧 Map 作为生成事实，不查 T2，不加发布锁。
- `MemoryMapService.generateAndPublish()` 供 CT19 后续复用，但不接 Runtime。

## 4. 失败矩阵

| 场景 | 期望 |
| --- | --- |
| Snapshot DB 失败 | 原持久化错误；0 LLM、0 发布 |
| T1 与集合 MAX 不一致 | 内部快照错误；0 LLM、0 发布 |
| 空库 | 0 LLM；1 次确定性空 Map safeReplace |
| 固定全量超预算 | `LOCAL_BUDGET_EXCEEDED`；0 LLM、0 发布 |
| LLM 网络失败 | 原 LlmException；0 发布 |
| finish_reason=length | `OUTPUT_TRUNCATED`；0 发布 |
| Parser/Validator 非法 | `INVALID_RESPONSE`；0 发布 |
| Renderer 失败 | 原错误；0 发布 |
| safeReplace 提交前失败 | 旧 Map 保留；错误传播 |
| safeReplace 状态失败 | `STATE_ERROR + PARTIAL`；完整新版可能已存在 |
| 生成期间新 Organized | 发布旧 T1；不查 T2 |
| 取消 | CancellationException 原样传播 |
