### 2.3 测试用例计数与 XML 报告严格对齐（源码 @Test vs XML 差额为 0）

通过独立 Python 脚本深度扫描所有测试源码中的 `@Test` 注解数量，并与 build 生成的 `TEST-*.xml` 报告中的 `tests="N"` 进行逐模块交叉核对：

```bash
$ python3 -c '
import os, xml.etree.ElementTree as ET

module_xml = {}
total_xml = 0
total_fail = 0
total_err = 0
total_skip = 0

for root, dirs, files in os.walk("."):
    if any(x in root for x in [".local", "tools", ".git"]):
        continue
    for f in files:
        if f.startswith("TEST-") and f.endswith(".xml"):
            path = os.path.join(root, f)
            b_idx = root.split(os.sep).index("build")
            mod = "/".join(root.split(os.sep)[:b_idx])
            tree = ET.parse(path)
            s = tree.getroot()
            t = int(s.attrib.get("tests", 0))
            module_xml[mod] = module_xml.get(mod, 0) + t
            total_xml += t
            total_fail += int(s.attrib.get("failures", 0))
            total_err += int(s.attrib.get("errors", 0))
            total_skip += int(s.attrib.get("skipped", 0))

print("Total XML tests:", total_xml, "Failures:", total_fail, "Errors:", total_err, "Skipped:", total_skip)
for m, c in sorted(module_xml.items()):
    print(f"  {m}: {c}")
'
```

## 5. 81 个 VFS 基线文件哈希比对结果

```bash
$ python3 -c '
import json, hashlib

with open(".local/validation/cm1/architect/vfs-baseline-sha256.json") as f:
    baseline = json.load(f)

mismatches = []
missing = []
for filepath, expected_hash in baseline.items():
    try:
        with open(filepath, "rb") as f:
            actual_hash = hashlib.sha256(f.read()).hexdigest()
            if actual_hash != expected_hash:
                mismatches.append((filepath, expected_hash, actual_hash))
    except FileNotFoundError:
        missing.append(filepath)

print(f"Total baseline files: {len(baseline)}")
print(f"Missing files: {len(missing)}")
print(f"Mismatches: {len(mismatches)}")
'

```
