## 2. Architect 独立连接语义核查

通过项目私有 JDK 的 `javap -c -p` 检查本地缓存 SQLDelight **2.1.0** 的 `JdbcSqliteDriverKt`、`ThreadedConnectionManager`、`StaticConnectionManager`，证据归档：`.local/validation/cm1/architect/sqldelight-connection-bytecode.txt`。

- 普通文件 URL 选择 `ThreadedConnectionManager`。
- `closeConnection(connection)` 要求在取得连接的线程调用；不存在驱动事务时实际关闭连接并移除 ThreadLocal。
- 该 Manager 的 `close()` 本身为空实现，不能用它代替手取连接的可靠释放。
- 因此，stock `JdbcSqliteDriver` 加固定线程不能直接作为 Slot 生命周期内固定连接、连接级 PRAGMA 持续有效的证明。

CT04 应显式持有物理 Connection，并以兼容 SQLDelight 的驱动适配绑定到 Slot，或采用有同等实证的方案。CT01 探针须反映 stock 驱动的真实行为；完整 Slot 的隔离、事务、取消与关闭验收留在 CT04。本次是字节码独立核查，尚未重跑修正后的兼容性探针。
