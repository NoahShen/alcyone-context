## 2. 冻结实现要求

### 2.1 公共模型

- `MapStatus`：CURRENT/STALE/MISSING/UNKNOWN。
- `MemoryMapView(content, generatedAt, sourceUpdatedAt)`。
- `BootstrapContext(memoryMap, mapStatus, capabilities)`。
- B1 不修改 `AlcyoneContext` 接口；`bootstrap()` 方法在 B2 接线。

### 2.2 配置

```yaml
context:
  memoryMap:
    refresh:
      periodic:
        enabled: true
        cron: "*/10 * * * *"
```

- `ContextConfig.memoryMap: MemoryMapConfig?`；缺省 null。
- 出现即启用；空映射默认 periodic。
- 固定 Asia/Shanghai；拒绝 timezone 键。
- Loader 严格 unknown/type/非法 cron。
- B1 只解析配置；LLM 绑定跨配置校验可在 B2 Factory 做，若 B1 提供纯校验 helper需在现有白名单内。

### 2.3 StatusTracker / BootstrapReader

- Tracker 线程安全保存最近 View/Status；Bootstrap 只取快照。
- Reader 读取固定 `alcyone://memory/map.md`，严格使用 CT18 `MemoryMapRenderer.parse`。
- VFS NOT_FOUND → MISSING；解析失败 → UNKNOWN；不查 DB、不调 LLM。
- 破损 Map 不返回破损内容；旧有效 View 可保留并标 UNKNOWN（待 D6）。

### 2.4 RefreshCoordinator

- `Channel<Unit>(CONFLATED)` + 单 Worker。
- `requestRefresh()` 合并信号；不并行生成。
- 每轮检查 DB MAX 与已发布 Map sourceUpdatedAt。
- CURRENT → skip；STALE/MISSING/UNKNOWN → CT18 `MemoryMapService.generateAndPublish()`。
- 生成中补信号最多保留一个，下一轮重新检查。
- 发布成功不查 T2；建议保守 STALE（待 D5）。
- 生成失败保留旧 View/Status；错误脱敏。
- CancellationException 原样传播；beginClosing 后拒绝新请求。

### 2.5 PeriodicCron

- UNIX 五字段，固定上海时区，默认 `*/10 * * * *`。
- 启动不立即扫描、严格未来、不补跑。
- 每 tick 做轻量 stale 检查，不等待 LLM。
- tick 重叠单飞跳过。
- 普通失败 WARN + 固定可取消退避，不紧凑循环。
- close 立即响应并 join。

### 2.6 Pipeline

- 组合 Tracker/Reader/Coordinator/Cron。
- `start()`、`activate()`、`beginClosing()`、`closeAsync()`。
- RUNNING/activate 前不执行生成。
- beginClosing 同步封准入；停 Cron；取消/join Worker；发布共享关闭结果。
- B1 不接 Factory/Impl/Organization wakeup；由 B2 接线。

## 4. 并发与失败矩阵

| 场景 | 期望 |
| --- | --- |
| 连续 request | CONFLATED 最多一个待处理信号 |
| Worker 执行中补信号 | 当前轮后再处理一次，不并行 |
| DB 已 CURRENT | 跳过 LLM/发布 |
| Map NOT_FOUND | MISSING；request 后生成 |
| Map 破损 | UNKNOWN；不返回破损内容 |
| stale Map | STALE；request 后生成 |
| 生成失败 | 保留旧 View/Status，记录脱敏错误 |
| safeReplace 失败 | 不伪 CURRENT；旧 Map/状态事实保留 |
| Cron tick 重叠 | 单飞跳过 |
| Cron 查询失败 | WARN + 可取消退避 |
| activation 前 | 不生成/发布 |
| beginClosing 后 | 拒绝新请求；不创建新 Worker |
| Worker/Cron 关闭 | 真实 join；CE 原样传播 |
| Bootstrap 并发刷新 | 返回最近缓存快照，不等待 LLM |
