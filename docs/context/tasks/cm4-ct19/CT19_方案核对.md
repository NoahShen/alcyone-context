## 2. 刷新架构

```text
Organization committed ─┐
Runtime start check ────┼→ requestRefresh()
Periodic Cron stale? ───┘
                              ↓
                 Channel<Unit>(CONFLATED)
                              ↓
                        唯一 Map Worker
                              ↓
            轻量 DB 水位 + 已发布 Map 检查
                    current → skip
                    stale/missing/invalid → CT18 generate+publish
                              ↓
                 更新 MemoryMapView / MapStatus
```

- Organization 轮次结束一次通知。
- 启动检查异步，不阻塞普通 Context 检索。
- Cron 只做轻量检查，不在 Cron 回调内等待 LLM。
- 生成期间补信号最多保留一个，下一轮重新检查。

## 3. 状态机候选

| 状态 | 含义 | Bootstrap |
| --- | --- | --- |
| CURRENT | 最近可靠检查确认 Map T1 == DB MAX | 返回 View + CURRENT |
| STALE | Map T1 < DB MAX | 返回旧 View + STALE |
| MISSING | 无可用 Map 文件 | null + MISSING |
| UNKNOWN | Map 破损或 DB/水位不可用 | 不返回破损内容；可返回已知旧 View + UNKNOWN（待 D6） |

- 启动前/首次检查完成前建议 UNKNOWN。
- Map 文件解析失败建议 UNKNOWN。
- VFS NOT_FOUND 建议 MISSING。
- DB 读取失败建议 UNKNOWN。
- 成功发布但生成期间可能有新写入且不查 T2：建议保守 STALE，下一轮检查再 CURRENT（待 D5）。

## 4. Bootstrap 候选

```kotlin
suspend fun bootstrap(): BootstrapContext
```

- 只读 `MemoryMapStatusTracker` 缓存。
- 不执行 DB read、不调用 VFS read、不调用 LLM、不 requestRefresh。
- `capabilities` 固定文本，不根据任务/Map 变化。
- Map 模块未配置时建议 `memoryMap=null, mapStatus=MISSING`（待 D1/D2）。
- Context 未启动/关闭时生命周期错误或 UNKNOWN（待 D7）。

## 5. 配置候选

```yaml
context:
  memoryMap:
    refresh:
      periodic:
        enabled: true
        cron: "*/10 * * * *"
```

- 缺省 `memoryMap=null`，不建 pipeline。
- 出现即显式启用，空映射使用默认 periodic 参数。
- 建议固定 `Asia/Shanghai`，`timezone` 作为未知键拒绝。
- 显式启用时要求 `context.llm` 中 `MEMORY_MAP` Task/Profile 且 JSON_SCHEMA/JSON_OBJECT。
- `periodic.enabled=false` 仍可由启动/Organization 触发。

## 8. 并发与取消矩阵

| 场景 | 期望 |
| --- | --- |
| 连续多次 request | CONFLATED 最多一个待处理信号 |
| Worker 执行中补信号 | 当前轮完成后再处理一次；不并行 |
| 同一轮内 DB 已 CURRENT | 跳过 LLM/发布 |
| 生成期间新 Organized | 不查 T2；本轮发布旧 T1；后续检查补偿 |
| Organization 通知丢失 | Cron 轻量检查追平 |
| Cron tick 重叠 | 单飞跳过，不并发检查 |
| STARTING/activation 前 tick | 不生成/发布 |
| beginClosing 后 request | 拒绝；不创建新 Worker |
| Worker LLM/发布中关闭 | 取消并真实 join；CE 传播 |
| Bootstrap 与刷新并发 | 返回最近已发布缓存快照，不等待 LLM |
| Map 读取/DB 检查失败 | UNKNOWN，不伪 CURRENT |

## 10. 失败矩阵

| 场景 | 结果 |
| --- | --- |
| DB 水位读取失败 | UNKNOWN；保留旧 View；不生成 |
| Map NOT_FOUND | MISSING；请求刷新 |
| Map parse 失败 | UNKNOWN；不返回破损内容；请求刷新 |
| Map stale | STALE；请求刷新 |
| LLM/生成失败 | 保留旧 View/Status；记录脱敏错误；等待下一触发 |
| safeReplace 提交前失败 | 旧 Map 保留；状态不伪 CURRENT |
| safeReplace PARTIAL | 旧/新内容按 CT17 事实；状态 UNKNOWN/STALE；错误记录 |
| Cron 查询失败 | WARN + 可取消退避；不紧凑循环 |
| 关闭中取消 | CE 原样传播；Worker/Cron join |
