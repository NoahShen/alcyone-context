## 1. 目标

CT19 只交付 Memory Map 生命周期与刷新协调：

```text
Organization 轮次通知 / Runtime 启动检查 / Periodic Cron
  → 轻量水位检查
  → Channel.CONFLATED 单 Worker
  → CT18 MemoryMapService.generateAndPublish()
  → Map 缓存 + MapStatus 四态

AlcyoneContext.bootstrap()
  → 只读缓存中的 MemoryMapView + MapStatus + capabilities
```

- 同一实例最多一个 Map Worker。
- 生成期间新请求最多保留一个待处理信号。
- 启动、Organization 通知、Cron 三类入口最终一致。
- Bootstrap 不查数据库水位、不调用 LLM、不主动触发刷新。

## 3. 冻结候选契约

### 3.1 公共 API

```kotlin
enum class MapStatus { CURRENT, STALE, MISSING, UNKNOWN }

data class MemoryMapView(
    val content: String,
    val generatedAt: Instant,
    val sourceUpdatedAt: Instant?,
)

data class BootstrapContext(
    val memoryMap: MemoryMapView?,
    val mapStatus: MapStatus,
    val capabilities: String,
)

interface AlcyoneContext {
    suspend fun bootstrap(): BootstrapContext
}
```

- `bootstrap()` 只读 Map 模块缓存。
- 不查 SQLite 水位、不读 VFS 新内容、不调 LLM、不发刷新任务。
- `capabilities` 为固定静态 Agent 使用说明。
- 默认第三方实现可安全返回 UNKNOWN + 空 Map + capabilities（待 D3）。

### 3.2 配置候选

```yaml
context:
  memoryMap:
    refresh:
      periodic:
        enabled: true
        cron: "*/10 * * * *"
```

- `ContextConfig.memoryMap: MemoryMapConfig?`；缺省 null 表示不建 Map pipeline。
- 出现即显式启用，空映射使用默认周期配置。
- 建议固定 `Asia/Shanghai`，不新增 timezone 键。
- 未配置 `MEMORY_MAP` Task/Profile 或非 JSON 模式 → `INVALID_CONFIG`（待 D2）。

### 3.3 MapStatus 四态

- `CURRENT`：最近一次可靠检查确认已发布 Map 水位与 SQLite 当前水位相同。
- `STALE`：已知 Map 低于 SQLite 水位。
- `MISSING`：尚无可用 Map。
- `UNKNOWN`：Map 破损或数据库/水位检查不可用，不能证明最新。

### 3.4 刷新协调

- `Channel<Unit>(CONFLATED)` + 唯一 Consumer。
- `requestRefresh()` 只合并待处理信号；Worker 执行期间新请求最多保留一个。
- 每轮先做轻量水位检查；已 CURRENT 则跳过实际生成。
- Organization 完整轮次结束后合并通知；启动检查一次；Cron 补偿。
- 单 Worker、单发布；生成期间新请求留待下一轮。

### 3.5 Bootstrap 读取

- 从缓存返回最近可靠 Map 状态；不主动 I/O。
- 旧 Map + STALE/UNKNOWN 可返回内容但必须明确状态。
- Map 缺失返回 `memoryMap=null, mapStatus=MISSING`。
- 破损 Map 不作为可用内容，返回 `UNKNOWN`。

### 3.6 生命周期

- RUNNING 前不得执行生成/发布。
- 进入 STOPPING 时同步封闭刷新准入，再停 Cron、取消并 join Worker。
- Worker 生成/发布中取消按 `CancellationException` 传播，VFS 由既有生命周期回收。
- 关闭后 Bootstrap 仍只读缓存或返回 CLOSED（待 D7）。

| 层 | 组件 | 职责 |
| --- | --- | --- |
| API | Map 三模型 + `bootstrap()` | 公共只读契约 |

| Runtime | `MemoryMapPeriodicCron` | 固定上海时区补偿 Cron |
| Runtime | `MemoryMapPipeline` | Coordinator/Cron/状态统一生命周期 |
| Runtime | Factory/Impl 接线 | wakeup、bootstrap、workers、关闭 |
