## 2. 冻结契约

### 2.1 VFS API

```kotlin
suspend fun safeReplace(
    uri: VfsUri,
    content: ByteArray,
): NodeInfo
```

- 显式 API，不扩展 `WriteMode`。
- 默认第三方实现返回 `UNSUPPORTED_OPERATION`；不承诺 JVM ABI 不变。
- 目标不存在可首建；存在文件可完整替换；目录拒绝；未注册物理文件可替换并登记。
- 保留已注册 Node 的 ID、Metadata、registeredAt；只推进 updatedAt。
- `FILE_CREATED` / `FILE_WRITTEN` 按替换前实际存在性产生。
- 临时文件不得登记 Node、不得发独立事件。

### 2.2 后端能力

- LocalFs：同 Mount、同目录唯一临时文件；完整写入并确认；真实原子 replace。
- 必须用真实 LocalFs 探针和失败注入证明，不得用未验证 OpenDAL rename 冒充。
- WebDAV：首版能力位为 false；`safeReplace` 返回 `UNSUPPORTED_OPERATION`；不得降级。
- 跨 Mount、目录、只读、超限、无能力均在产生目标副作用前拒绝。

### 2.3 失败语义

| 阶段 | 结果 |
| --- | --- |
| 原子提交前失败/取消 | 旧文件逐字节不变；临时文件清理 |
| 原子 replace 成功、Node/Event 提交成功 | 新完整文件；成功返回 NodeInfo |
| 原子 replace 成功、Node/Event 提交失败 | 新完整文件保留；`STATE_ERROR + PARTIAL` |
| 原子 replace 失败 | 不伪造成功；按已验证事实报告 effect，禁止非原子降级 |

不得声称 SQLite/VFS 联合原子回滚。

### 2.4 Resource（B2 冻结，B1 不实现）

- 只允许 `/resources/<non-empty>` 文件。
- `ResourceMetadata(uri, sizeBytes, modifiedAt)`；null 表示后端不提供。
- 新增 `ContextResourceException` 安全错误码。
- `read` 复用 VFS 16 MiB 可配置上限。
- `readStream` 冷 Flow、64 KiB 分块、每次 collect 独立开/关流。
- 完成、异常、取消、提前结束均关流；不承诺打断阻塞 native read。
- 缺 `resources` mount 时调用时具名失败，不破坏最小配置启动。
- `loadMeta` 允许 VFS Node 懒注册，但不发文件变更事件、不写 Resource 内容。
