## 2. 实现范围

### 2.1 B1：VFS 安全发布

- 新增显式 `Vfs.safeReplace(VfsUri, ByteArray): NodeInfo`。
- `StorageCapabilities.atomicReplace` 与 internal Storage 原语。
- LocalFs 同目录临时文件、完整写入/确认、真实原子 replace。
- WebDAV 明确 `UNSUPPORTED_OPERATION`，无普通覆盖/删除后 MOVE 降级。
- DefaultVfs 单状态锁编排、Node ID/Metadata/registeredAt、FILE_CREATED/FILE_WRITTEN。
- 原子提交前失败旧文件逐字节不变。
- 物理替换成功、Node/Event 提交失败返回 `STATE_ERROR + PARTIAL`，完整新版保留。
- AlcyoneVfs 在途登记、关闭/取消生命周期。

### 2.2 B2：Context Resource 访问

- `AlcyoneContext.loadMeta/read/readStream`。
- `ResourceMetadata(uri, sizeBytes, modifiedAt)`。
- `ContextResourceException` 安全错误码。
- 严格 `/resources/<non-empty>` 文件 URI gate。
- `read` 复用 VFS 16 MiB 可配置 ByteArray 限额。
- `readStream` 冷 Flow、64 KiB 分块、每次 collect 独立开关流。
- 完成、异常、取消、提前结束关流；close 失败优先级与 suppressed 规则。
- 缺 resources mount 时调用时失败，不破坏最小配置启动。
- `loadMeta` 允许 VFS Node 懒注册，不发文件变更事件、不写 Resource 内容。
