```text
Vfs.safeReplace
```

## 2. 冻结实现契约

### 2.1 公共 API

```kotlin
suspend fun safeReplace(
    uri: VfsUri,
    content: ByteArray,
): NodeInfo
```

- 不扩展 `WriteMode`。
- `Vfs` 默认实现抛 `VfsException(VfsErrorCode.UNSUPPORTED_OPERATION, ...)`；不承诺 JVM ABI 不变。
- `DefaultVfs` 与 `AlcyoneVfs` 必须覆盖真实实现。

### 2.2 Core 编排

`DefaultVfs.safeReplace` 应复用现有写入链的已验收组件，至少满足：

1. `content.size <= VfsLimits.defaultWriteMaxBytes`，超限在碰存储前拒绝。
2. 在 `StateBoundary` 单锁内完成预检、父目录、Storage 调用和 Node/Event 提交。
3. 路由必须命中目标 Mount；不跨 Mount、不复制回退。
4. 目标目录拒绝；只读、结构保护、父路径类型冲突按现有错误契约拒绝。
5. 目标不存在允许首建；父目录缺失允许在目标 Mount 内补建。
6. 已注册 Node 类型不是文件时按现有写路径拒绝。
7. Storage 成功后在同一事务提交 Node/Event；已有 Node 保留 ID、Metadata、registeredAt，只推进 updatedAt。
8. 替换前实际不存在 → `FILE_CREATED`；已存在 → `FILE_WRITTEN`。
9. 不得创建临时 Node、不得为临时文件发事件。
10. `CancellationException` 原样传播，不包装。

### 2.3 Storage 能力

建议在 `StorageCapabilities` 增加：

```kotlin
val atomicReplace: Boolean = false
```

在 `Storage` 增加内部原语：

```kotlin
suspend fun safeReplace(
    path: StoragePath,
    content: ByteArray,
): StorageAttributes
```

- `Storage` 默认实现可抛 `UNSUPPORTED_OPERATION`，避免无关替身被迫扩写；真实 LocalFs 覆盖。
- `DefaultVfs` 必须在调用前检查 `atomicReplace`，不得只依赖后端异常。
- WebDAV 能力位为 `false`，`safeReplace` 返回 `UNSUPPORTED_OPERATION`，不触网络。

### 2.4 LocalFs

- 同 Mount、目标同目录创建唯一临时文件；不得跨文件系统。
- 临时文件内容完整写入并 `stat` 确认；失败时旧目标不得改变。
- 使用真实同文件系统原子 replace；实现可以评估 `Files.move(temp,target,ATOMIC_MOVE,REPLACE_EXISTING)`，但必须用真实探针确认当前 JVM/平台对既有目标的精确行为。
- `AtomicMoveNotSupportedException` 或等价“无原子能力”必须映射 `UNSUPPORTED_OPERATION`，禁止回退普通 move/覆盖/删除。
- 临时文件必须使用安全、不可预测且不覆盖已有文件的名称；临时文件不得暴露为 VFS 路径。
- 成功、失败、取消均尽力清理临时文件；清理失败不得覆盖主异常，按事实报告 effect。
- 关闭后调用必须 `CLOSED`。

### 2.5 WebDAV

- 不新增真实 WebDAV safeReplace 支持。
- 能力位 `atomicReplace=false`。
- 直接调用 Adapter `safeReplace` 也返回 `UNSUPPORTED_OPERATION`，不发网络请求。
- 不得修改既有 WebDAV write/move 行为。

### 2.6 Runtime

`AlcyoneVfs.safeReplace` 必须走现有 `operation("safeReplace")` 在途登记：

- OPEN 时正常执行；
- CLOSING/CLOSED 拒绝；
- close 等待在途 safeReplace 或按既有宽限期请求取消；
- 不绕过 Runtime 直接调用 delegate。

## 4. 失败矩阵

| 场景 | 目标内容 | VFS 结果 |
| --- | --- | --- |
| 参数/URI/超限/路由/只读/结构/目录/能力 false | 旧内容不变 | 原错误码，`effect=NONE` |
| 补父目录中途失败 | 目标不变 | 原错误码，`effect=PARTIAL`（已建目录） |
| 临时文件写入/确认失败且清理成功 | 旧内容逐字节不变 | 原错误码；不得报成功 |
| 临时文件清理失败 | 旧内容不变，临时文件可能残留 | 原错误码，`effect` 至少 `PARTIAL` |
| 原子 replace 前取消 | 旧内容不变 | `CancellationException`；临时文件尽力清理 |
| 无原子能力 | 旧内容不变 | `UNSUPPORTED_OPERATION`，禁止普通 move/覆盖降级 |
| 原子 replace 失败且确认目标未变 | 旧内容不变 | 原错误码；effect 按已验证事实报告 |
| 原子 replace 成功、状态提交成功 | 完整新版 | 成功；Node/Event 正确 |
| 原子 replace 成功、状态提交失败 | 完整新版 | `STATE_ERROR` + `PARTIAL`；不尝试伪回滚 |

任何错误都不得把普通 `write(REPLACE_EXISTING)`、`delete + move` 或跨 Mount 复制作为 safeReplace 降级。

## 5. 测试矩阵

### 5.1 API

| 用例 | 断言 |
| --- | --- |
| 默认实现 | 未覆盖 `safeReplace` 的实现返回 `UNSUPPORTED_OPERATION`，无其他操作 |

| 纯净性 | api classpath 仍无 OpenDAL/JDBC/SQLDelight/NIO 物理路径泄漏 |

### 5.2 Core 编排

| 用例 | 断言 |
| --- | --- |
| 首次创建 | 目标缺失→写完整内容；`FILE_CREATED`；登记新 Node；父目录可补 |
| 已注册替换 | Node ID/Metadata/registeredAt 不变；updatedAt 前进；`FILE_WRITTEN` |
| 未注册已有文件 | 物理旧文件可替换；成功后登记；`FILE_WRITTEN` |
| 内容超限 | 碰 Storage 前 `LIMIT_EXCEEDED`/`NONE` |
| 无 Mount/只读/目录/父路径冲突 | 原错误码/NONE；无 safeReplace/write/move/delete 副作用 |
| 能力 false | `UNSUPPORTED_OPERATION`/NONE；Storage safeReplace 0 调用 |
| 父目录补建失败 | 保留原错误；effect PARTIAL；无目标 Node/Event |
| Storage 预提交失败 | 旧目标字节不变；无 Node/Event |
| Storage 成功、状态提交失败 | 新目标完整存在；`STATE_ERROR`/PARTIAL；无已提交 Node/Event |
| 取消 | CE 原样传播；已产生副作用如实处理 |
| 禁止降级 | 调用记录无 delete/move/普通 write 替代 |

### 5.3 LocalFs 真实探针

| 用例 | 断言 |
| --- | --- |
| 首建 | 真实目录出现完整目标；无临时文件残留 |
| 替换已有 | 目标逐字节变为新内容；临时文件消失；旧 Node 不在此层 |
| 原子能力探针 | 当前 JVM/平台真实 `ATOMIC_MOVE` 行为被直接验证；不支持则 `UNSUPPORTED_OPERATION` |
| 临时写失败 | 旧目标逐字节不变；无半写目标 |
| 原子 replace 失败 | 旧目标逐字节不变或事实 UNKNOWN/PARTIAL，禁止伪成功 |
| 清理失败 | 主错误保留；effect 反映临时残留 |
| 取消边界 | rename 前取消旧目标不变；资源尽力清理 |
| 关闭后调用 | `CLOSED` |

真实 LocalFs 测试不得只 mock `Files.move`；替身可补失败阶段，但原子成功/旧目标行为必须至少有一条真实文件证据。
