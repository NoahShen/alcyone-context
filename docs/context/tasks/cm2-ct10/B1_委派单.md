## 2. 锁定的实现契约

### 2.1 `ExtractionContext`（D2）

```kotlin
class ExtractionContext(
    val sessionKey: SessionKey,
    turns: List<StoredConversationTurn>,
) {
    val turns: List<StoredConversationTurn> // 防御性复制 + 不可修改
}
```

- 构造时复制 `turns` 并包装为不可修改列表；不新增 `targetTurnIds`/`historyTurns` 字段；Target 由调用方按 `extractionStatus == PENDING` 判定。
- 提供稳定 `equals/hashCode/toString`（不泄漏正文之外内容；toString 不展开 messages 全文，避免日志风险）。

### 2.2 `ExtractionBuildResult`（D1）

sealed interface ExtractionBuildResult {

    data class FixedOverheadOverBudget(val requiredTotalTokens: Long) : ExtractionBuildResult

- 字段名固定；只含 anchor id / requiredTotal；**不携带 Prompt/正文/Key/URL**。

### 2.4 `ExtractionPrompt` v1（D3/D12）

- `object ExtractionPrompt`，公开常量 `VERSION = "v1"`、`SCHEMA_VERSION = "v1"`。
- `systemPrompt(): String`：读取 `prompts/extraction-v1.md`；内容覆盖六原则、Target/History 区分、只输出 JSON `memories` 契约、禁止把 Assistant 建议冒充用户决定、时间表达规则；不含 Key/URL/无关元数据。
- `schema(): String`：读取 `prompts/extraction-schema-v1.json`；对应设计输出：
  `{ "memories": [ { "content": string(non-empty), "source_turn_ids": int[] (non-empty) } ] }`；`additionalProperties:false`；不要求模型输出系统字段。
- `messages(turns: List<StoredConversationTurn>): List<LlmMessage>`：
  - 返回 `system` 消息（systemPrompt） + `user` 消息（渲染所有 Turn；空列表时 user content 为空字符串，用于基础请求的协议开销）。
  - 每个 Turn 严格按：
    ```text
    <turn id="1001" timestamp="2026-10-30T10:00:00.000+08:00" target="true">
    user: ...
    assistant: ...
    </turn>
    ```
  - `target=true` iff `extractionStatus == PENDING`；complete/failed 为 false；Turn 顺序按传入顺序（真实会话顺序）；timestamp 用既有 `TimeCodec.format`（+08:00 固定毫秒）；角色/正文原样，不增删消息。
  - 渲染稳定可测试；不包含 Key/URL/数据库内部额外元数据。
- 资源读取失败应在初始化/调用时明确失败（不静默空字符串）；资源位于 Core jar classpath。

### 2.6 纯预算分类（D5/D6，B1 只做纯函数）

`internal object ExtractionBudgetPolicy`（runtime/extraction）：

```kotlin
internal sealed interface ExtractionBudgetStatus {
    data object Fits : ExtractionBudgetStatus
    data class Over(val requiredTotalTokens: Long) : ExtractionBudgetStatus
}

internal object ExtractionBudgetPolicy {
    fun classify(decision: LlmBudgetDecision, task: LlmTaskConfig, profile: LlmProfileConfig): ExtractionBudgetStatus
    fun nextWindowSize(current: Int): Int // max(1, current / 2)
}
```

- `classify`：`estimatedInputTokens <= task.maxInputTokens` 且 `requiredTotalTokens <= profile.contextWindowTokens` → Fits；否则 Over(requiredTotal)。
- `nextWindowSize`：`max(1, current / 2)`；序列 32→16→8→4→2→1、10→5→2→1、1→1。
- 不调用 LLM、不写库、不抛 `LOCAL_BUDGET_EXCEEDED`；B2 Builder 复用。
