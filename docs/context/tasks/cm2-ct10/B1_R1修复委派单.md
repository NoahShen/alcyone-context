## 2. 锁定的 Prompt v1 内容要求

System Prompt 必须显式覆盖设计六原则（可用小节/编号，但内容必须可验证）：

1. **价值优先**：长期有用的事实/偏好/约束/决定/目标；忽略寒暄与一次性细节。
2. **忠实来源**：只提取用户明确表达/确认；不推测、不编造；不得把 Assistant 建议/示例冒充用户决定，除非明确采纳。
3. **完整原子化**：单条记忆是独立、可复用的**最小完整语义**；保留必要原因、条件、时间与背景；避免碎片化或堆叠无关事实。
4. **关注重要变化**：优先决策、偏好、约束、目标变化、已验证经验、研究结论、失败/否定性结果及重要理由。
5. **批内去冗余**：同一批 Pending Turn 中重复表述可合并并引用多个来源；不检索已有 Raw Memory 做跨批去重，不同时间再次确认允许再提取。
6. **证据可追溯**：每条记忆至少一个真实来源 `source_turn_ids`，至少一个是 Target；保留原文不确定性，不猜测、不强行提取。

同时保留/强化：
- Target/History 明确区分（target=true 为目标；history 只作语境，不得单独作为新记忆来源）。
- 时间表达：相对时间必须依据 Turn `timestamp` 给出绝对锚点；不补造用户未给出的时间。
- JSON 输出契约：只输出 `{ "memories": [ { "content": "...", "source_turn_ids": [1001] } ] }`；`memories` 可为空；不输出系统字段；不加 Markdown 围栏/解释。
- 不含 API Key、URL、数据库内部额外元数据。
