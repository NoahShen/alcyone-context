## 5. 真实保证边界（不外推）

- **跨进程并发**：同一业务键同内容在同一执行器内返回CREATED/DUPLICATE；CAS竞争返回1/0，重复来源关联仍按唯一约束报错；跨进程竞争未在本轮验证，可能出现BUSY/快照竞争等持久化失败，不保证固定为UNIQUE/FK；不承诺自动重试或合并。
- **全局水位**：`advanceUpdatedAt` 只写入调用方传入的 `next`；严格递增由调用方在同一写事务内先 `maxUpdatedAt()` 再分配（`max(now 毫秒, previous+1ms)`），实现不自动修正任意 `next`。
- **查询顺序**：`findByIds` 不保证输入顺序；Organized批量/分页查询附加来源时为N+1（单条findById为两次查询）（B3 未做批量优化，热点需另行评估）。
- **多语句**：CT04 `SqlBoundaryGuard` 整体阻断多语句，严于最小要求；如未来需要放开须另行评审。
- **未覆盖**：43 例真实 WebDAV 未重跑（无相关改动）；Runtime 组装/生命周期接线属 CT06；真实模型评测、HTTP 与部署属后续任务。
