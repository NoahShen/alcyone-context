## 2. 方案摘要

- **Schema**：`.sq` 文件即唯一结构事实来源，`ContextDatabaseSqlite.Schema.version` 与 `PRAGMA user_version` 对齐为 1；Checkpoint 初始行通过 `.sq` 内的初始化语句生成。
- **Slot**：`ContextSlot` 自持 `Connection` + `ExecutorService`（单线程），`SlotJdbcDriver` 继承 SQLDelight `JdbcDriver` 并把 `getConnection()` 固定为该 Slot 的连接、`closeConnection()` 置空，逐语句不关闭连接。事务在写 Slot 物理连接上以 `autoCommit=false` 执行，同步 commit / rollback 后恢复。
- **初始化**：显式入口在独占新文件上建 Schema 并写版本；普通打开先以 `file:...?mode=ro` 只读连接校验存在性、非空与 `user_version`，全部通过后才打开读写 Slot。
- **生命周期**：Slot 记录在途执行计数；`close` 先置关闭闸门拒绝新请求，再等待在途归零，最后逆序关闭物理连接与线程。
