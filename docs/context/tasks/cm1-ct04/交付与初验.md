## 3. 设计落点（对照实现方案）

1. **Schema**：`.sq` 即事实来源，生成类的 `Schema.version == 1`，六表、五索引、Checkpoint 初始行经 `PersistenceSkeletonTest` 外的 A01/A09 逐项断言。
2. **Slot**：`SlotConnectionJdbcDriver` 继承 `JdbcDriver`，`getConnection` 固定、`closeConnection` 空操作；`ContextSlot` 自持连接与单线程 `dispatcher`；PRAGMA 在创建时一次性设置，A03 逐语句后断言持续。
3. **执行器**：写串行（`Semaphore(1)`）+ 读轮转/排队；事务 `autoCommit=false → commit/rollback → restore`；读显式事务快照；嵌套/逃逸/跨线程/Savepoint 全部具名拒绝；`CancellationException` 原样传播。
4. **初始化**：已存在（含 0 字节）拒绝、不覆盖；建库失败清 `-wal`/`-shm`；父目录自动创建。
5. **打开保护**：只读校验先行（存在→非空→`user_version==1`→结构齐备），错版文件主库字节不变；全程不调用 `Schema.create/migrate`。
6. **生命周期**：`closeAsync`（挂起）与 `close`（`AutoCloseable`）幂等；挂起式 `awaitDrained` 等在途，不占线程；逆序释放读→写；失败启动逆序释放；关闭后全部入口抛 `CLOSED`。
7. **公共能力**：`ContextDbTime` 仅是 `TimeCodec` 的数据库边界封装；`persistence-sqldelight` 显式 `implementation(projects.common)`，不依赖 Core 传递。
