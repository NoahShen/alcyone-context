## 2. 建议全景链

```text
start
  → 5 Conversation Turns
  → Extraction LLM
  → Raw + Pending
  → Organization Governance LLM
  → Organized + Source + watermark
  → Organization Map wakeup
  → Map LLM
  → safeReplace alcyone://memory/map.md
  → bootstrap
  → Search Scanner + Rerank
  → getMemory/getRawMemory
  → Memory 内 Resource URI
  → loadMeta/read/readStream
  → close
```

- 空库启动检查可先发布确定性空 Map，不调用 LLM。
- Organization committed 后 Map wakeup 生成真实 Map。
- Search 返回动态 Organized ID，需要动态 HTTP stub 从 SQLite 读取 ID。
- Resource URI 由 Memory 内容提供，不由测试硬编码到读取阶段。

## 4. 全景链测试要点

- 真实 Factory + initializeDatabase + start/close。
- 真实 SQLite；真实 VFS LocalFs `/memory` 与 `/resources` 双挂载。
- 真实 Ktor client + JDK HTTP stub。
- Fake LLM 响应顺序/类型可动态路由；请求体不含/不记录 Key 原文。
- Extraction 响应含 Resource URI；Governance NEW 保存真实 Organized/Source。
- Map 响应 Domain 必须与真实 Organized Domain 一致。
- Search Scanner/Rerank 返回真实动态 ID。
- bootstrap 在 Map 发布前可 MISSING/UNKNOWN，发布后 STALE/CURRENT。
- Get/GetRaw 不新增 LLM 请求。
- Resource Meta/Read/Stream 使用 Search/Get 返回内容中的 URI。

## 5. Map 交错测试要点

- 第一版 Map 完整。
- 第二版生成被可控 HTTP gate 阻塞。
- bootstrap 轮询窗口内只返回第一版完整内容；Front Matter 严格可解析。
- 旧版不会因读取与 safeReplace 交错出现半写。
- 释放后第二版完整，sourceUpdatedAt 新水位；下一轮检查 CURRENT。
- 不修改 CT18 Publisher/CT19 Pipeline 语义。

## 6. Search→Resource 取消测试要点

- Search 返回包含 `alcyone://resources/...` 的真实 Memory。
- Resource 文件至少 >128 KiB，以覆盖多个 64 KiB 块。
- `read` 与 `readStream` 内容一致。
- collector 首块后挂起并取消，tracked stream count 最终 0。
- 再次打开 stream 后 closeAsync，stream 被回收，close 有界完成。
- close 后新 collect 为 CLOSED。

## 7. 固定集候选

### 7.1 Map

- 长期目标/稳定偏好/当前重要事项覆盖。
- 不确定性保留（不得把待确认事项写成确定事实）。
- 真实 Domain、导航可用、不伪造 Resource URI。
- 空库/单条/多 Domain/重要变化。

### 7.2 Search

- 明确相关、同义表达、多候选排序。
- Domain 过滤、时间/范围相关。
- 无匹配返回空。
- 模型不得返回输入外 ID/正文。

### 7.3 归档

- 合成/脱敏输入。
- 预期语义约束、禁止错误、人工参考说明。
- Prompt/Schema SHA、Fake Profile/Task、样本版本。
- Fake 结果和真实模型结果分栏；真实模型 not-run。
