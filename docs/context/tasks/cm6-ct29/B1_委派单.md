## 2. Server精确范围

新增生产 `StandaloneMain.kt`、`StandaloneCommand.kt`；新增 `StandaloneCommandTest.kt`。不修改build.gradle.kts/Application、Managed生产。

命令严格：

```text
alcyone-context init --config <yaml>
alcyone-context upgrade --config <yaml> --backup-dir <existing-directory>
alcyone-context run --config <yaml>
```

无默认run/init；未知/重复/缺失/错用选项均2。相对YAML按进程CWD，YAML内相对路径仍由Loader解析。两个现有Loader纯校验后再执行命令。

- init：唯一 `AlcyoneContextFactory.initializeDatabase`，任何既有文件拒绝不覆盖；成功stdout仅 `INITIALIZED`。
- upgrade：Loader→源只读验版/结构→完整离线备份→独立quick_check→当前v1才no-op；stdout仅 `NO_OP schema_version=1 backup_id=<仅文件名>`。无绝对路径/YAML/Key/异常文本；高低版绝不成功。无 `.sqm`，不宣称迁移/回滚。
- run：B1可接入既有Managed或直接保留到B2真实进程，但不得新增第二套启动；配置有效后的启动/关闭失败4。init/upgrade不构造Context/Managed/CIO、不创建VFS DB、不启动Worker/Cron/Ktor。
- 退出码0成功/no-op，2用法/配置，3 init/upgrade持久化/版本/备份，4 run启动/关闭；stderr固定安全code。未知普通异常按所在命令3/4；CancellationException/VM fatal Error不吞。main统一exitProcess，runner可直接测试；避免测试中杀Lead JVM。
