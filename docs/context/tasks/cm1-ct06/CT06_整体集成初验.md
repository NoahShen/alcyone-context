## 4. CT01 冻结契约 / 依赖方向 / 实际可用功能

- **冻结契约**：`AlcyoneContext : AutoCloseable` 位于 `com.github.noahshen.alcyone.context.memory.api`，`suspend start()`、`override fun close()`、`suspend closeAsync()`、`suspend getStatus()`；未追加 CT07 业务入口（无 TODO/假实现）。
- **依赖方向**：`api → 仅 coroutines`（无 common 项目依赖）；`core → api + common`；`persistence → api + core + common`；`runtime → api + core + persistence + vfs.runtime`；`server → runtime`。api 不依赖 Runtime/JDBC/YAML。
- **实际可用功能**：配置加载与校验、VFS 配置映射、数据库显式初始化、普通 start 拒启保护、生命周期与关闭、`getStatus`（lifecycle/workers 空/storage 缓存事实）。**未实现**：Ingestion 业务入口（CT07）、Worker/Cron/LLM、HTTP（CT07）。`workers` 为空 Map，不虚报运行态。
