## 4. 运行结果与失败候选

### 4.1 成功/无工作

- 无新增：`start=C0,end=C0,scanned=0,topics=0,memories=0,completed=true`。
- 完整成功：`start=C0,end=U,scanned=(C0,U]实际行数,topics/memories=processor聚合,completed=true`。

### 4.2 失败

- ALREADY_RUNNING：不进入扫描，无 partialResult。
- Batch/processor失败：停止后续批次，partialResult.endCheckpoint=最后成功 batch 的 lastTurnId；cause 保留具名底层错误。
- 单 Turn 超预算：当前批次无成功，partialResult 可回退到最后成功批次；Checkpoint 保持。
- DB checkpoint/max读取失败：原 ContextPersistenceException。
- CE：原样传播，不包装。

## 5. 固定范围与预算细节

- 初始 `database.read` 只读 C0/U；不在事务内读全量或调 LLM。
- 后续 `idRange(lastRead,U,pageSize)` 必须递增；空页/不足页表示当前 U 范围读取完成。
- ID 空洞合法；`scannedTurns` 统计实际返回行数。
- 每批由完整 Topic Discovery 请求渲染后的 Token 预算决定；固定开销/单条超限 fail closed。
- 不允许跳过失败 Turn；不允许因 page 边界漏行；不允许根据 `timestamp`/extractionStatus 选择。

## 6. 单 Worker / Cron 候选

- Manual `runOnce` suspend，直接获取 single-run guard。
- Cron tick 只调用 `requestRun()`；guard busy 时 skip + 脱敏日志，不创建第二个 Worker。
- Cron 使用 UNIX 五字段；可选 timezone，缺省 Asia/Shanghai；start 不立即运行，严格未来，不补跑。
- close：关闭 Cron 请求门 → 停止 Cron → 取消/join owned run → 共享结果。
- 无持久 queue/trigger counter。
