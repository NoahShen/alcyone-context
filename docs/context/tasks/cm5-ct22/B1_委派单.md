## 2. 冻结行为

### 2.1 公共模型

`DreamingResult` 放 `context/api`：

```kotlin
data class DreamingResult(
    val startCheckpoint: Long,
    val endCheckpoint: Long,
    val scannedTurns: Int,
    val discoveredTopics: Int,
    val generatedMemories: Int,
    val completed: Boolean,
)
```

- 所有 checkpoint/计数非负，`startCheckpoint <= endCheckpoint`。
- 正常/无工作返回 `completed=true`。
- partial failure 不返回 `completed=false` 的 RunResult；一律抛具名异常并携带 `partialResult`，其 `completed=false` 只存在于异常中。
- 不暴露 `StoredConversationTurn`/SQLite 内部类型到公共 RunResult。

### 2.2 错误契约

新增 `ContextDreamingException.kt`：

- `ContextDreamingErrorCode { ALREADY_RUNNING }` 至少。
- `ContextDreamingException(ALREADY_RUNNING, message)`，无 cause。
- `DreamingRunStage { FIXED_RANGE, PAGE_READ, BUDGET, BATCH_PROCESSING }`。
- `DreamingRunException(stage, partialResult, message, cause?)` 继承既有 ContextException。
  - `partialResult.endCheckpoint` = 最后成功批 lastTurnId；首个失败时可用 `start=end=startCheckpoint`、计数 0、`completed=false`。
  - DB/LLM 原异常作为 cause 保留；CE 永不包装。

### 2.3 Config / Loader

```yaml
context:
  dreaming:
    cron: "0 3 * * *"
    timezone: "Asia/Shanghai"
```

- `DreamingConfig()` 始终存在，`cron=null` 为 manual-only。
- `ContextConfig.dreaming` 新字段带默认值，旧 Kotlin 构造兼容。
- flat `cron: String?` + `timezone: String = "Asia/Shanghai"`。
- `cron` 出现时必须 UNIX 五字段；缺省不建 Cron。
- `timezone` 缺省 Asia/Shanghai；出现时必须 IANA ZoneId。
- 无 cron 但 YAML 显式出现 timezone → INVALID_CONFIG。
- Loader 严格拒绝 unknown/type；不校验 Dreaming LLM Task（后续任务）。

### 2.4 Fixed Range

- 每轮单次 `database.read` 同时读取 checkpoint C0 与 `maxTurnId()=U`。
- 校验 `0 <= C0 <= U`；违反 → `DreamingRunException(FIXED_RANGE, ...)`。
- U 固定；读取后新 Turn > U 不进入本轮。
- 无新增（U=null 或 U==C0）→ start=end=C0、scanned/topics/memories=0、completed=true。
- 后续分页 `idRange(lastReadId, U, pageSize)`，pageSize 默认 256；下界用上一页末 ID，不依赖“每页行数==pageSize”假设；空页/不足页终止。
- ID 空洞合法；pending/complete/failed 全部参与；不按 timestamp/status 过滤。

### 2.5 Token Batch / Processor Seam

`DreamingBatchProcessor.kt`（Runtime internal）：

```kotlin
internal fun interface DreamingBatchProcessor {
    suspend fun process(batch: List<StoredConversationTurn>): DreamingBatchOutcome
}

internal data class DreamingBatchOutcome(
    val lastTurnId: Long,
    val discoveredTopics: Int,
    val generatedMemories: Int,
)

internal fun interface DreamingBatchBudget {
    suspend fun requiredTotalFor(batch: List<StoredConversationTurn>): Long?
}
```

- processor `lastTurnId` 必须等于本批最后 TiD，且不得批外/回退；否则 DreamingRunException。
- `DreamingBatchBudget` 返回 null 表示预算内，否则 requiredTotalTokens；CT22 测试用受控 estimator/fake，CT23 接真实 Topic Prompt。
- 直接复用 `TokenBatchPlanner`；预算异常映射 `DreamingRunException(BUDGET)`，不改 planner 语义。
- 固定开销/单 Turn 超预算 → 当前 run 具名失败；不截断/跳过/修改 extraction_status。
- D16 主选跨页 streaming assembler：穷尽 `(C0,U]`，允许 batch 跨页，页间以上一页末 ID 衔接。
- 若跨页风险高，允许退回“批次不跨页”保守实现，但必须交付报告说明并测试页边界批完整性；不得漏行。

### 2.6 DreamingRunCoordinator

- 单实例最多一个 run；manual 重叠立即 `ALREADY_RUNNING`，不等待/排队。
- manual `runOnce()` 在 caller coroutine 执行；caller CE 原样传播。
- Cron `requestBackground()` 只启动 owned run；running 时 skip + 固定脱敏日志，不累加 trigger。
- close 只取消/join owned run；外部 caller 的 manual run 不被强杀，但组件进入 closing 后拒绝新请求。
- Coordinator 串行 process batches；每批成功后更新内存 endCheckpoint/counts；失败停止后续批次。
- CT22 不写 Raw/Pending/Checkpoint；真正 CAS 写事务留 CT25。
- Coordinator 可以暴露 internal test accessors：worker/round/request/queue/owned-job 状态。

### 2.7 DreamingPeriodicCron

- 仅当 `DreamingConfig.cron != null` 创建。
- UNIX 五字段 + 配置 timezone；启动不立即 run、严格未来、不补跑。
- 每 tick 只 `requestBackground()`；running skip 不回压 loop。
- 普通 tick/调度失败固定 1s 可取消退避 + 脱敏 WARN。
- close 立即取消并真实 join，共享 close 失败。

## 4. 测试矩阵

### 4.1 API

- DreamingResult六字段、非负/start<=end。
- ALREADY_RUNNING 错误码/消息/cause；DreamingRunException partialResult/stage/cause。

### 4.2 Config / Loader

- DreamingConfig manual-only 缺省、cron override、timezone default/IANA。
- 非法/空 cron、非法 timezone、无 cron 显式 timezone。
- Loader dreaming 缺省/空 mapping/覆盖/unknown/type。
- ContextConfig旧构造默认 dreaming。

### 4.3 Fixed range

- empty table/no new/U==C0、C0>U失败、C0负值失败。
- `(C0,U]` id ASC、ID 空洞、pending/complete/failed、U 后新 Turn 排除。
- 页尾衔接用上一页末 ID；整页/不足页/空页终止；不依赖 page size 假设。

### 4.4 Budget / processor

- 单批/多批、跨页 streaming（或保守 fallback+页边界测试）。
- 固定开销/单 Turn 超预算、预算等号。
- processor 串行、outcome lastTurnId单调/等于批尾、计数聚合。
- processor返回批外/回退/错误 → 具名失败；任一批失败后续0调用。
- partialResult endCheckpoint=最后成功批；DB/LLM cause保留；CE原样。

### 4.5 Single Worker / Cron

- manual running ALREADY_RUNNING；第二个 run 不启动。
- Cron running skip/0 new owned run；Cron只请求不等待。
- Cron start不立即 tick/严格未来/不补跑/失败退避/close join。
- close只取消 owned run；外部 manual run CE不被包装。
