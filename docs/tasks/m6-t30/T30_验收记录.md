### 2.4 实测结论
1. **模式与文件布局**：在 Alcyone VFS 正常关闭后，SQLite 处于默认 `delete` 模式，目录中保留 SQLite 主数据文件 `state.db`、已释放的 OS 独占锁文件 `state.db.lock` 以及物理文件目录 `docs/`；不存在任何 `wal`、`shm` 或 `journal` 伴随文件。
2. **冷备份有效性**：在正常关闭、完全保留 `state.db` 与物理文件目录的前提下，原路径物理彻底删除后进行回拷恢复，重新打开的 VFS 能无缝接续所有逻辑 Node ID、数据内容与元数据。
3. **边界限定**：上述结论仅适用于正常关闭状态下的冷备份，不涵盖进程崩溃后的残留 `journal` 状态，亦不承诺在线快照或跨后端分布式原子恢复。
