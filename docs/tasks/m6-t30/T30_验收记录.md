## 2. 离线备份与隔离验证实测记录

在临时隔离环境中执行了端到端冷备份与恢复验证：
1. **测试逻辑流程**：
   - 使用临时工作目录创建 `state.db` 与物理目录 `original/docs`；
   - 启动 VFS，写入文件 `backup_test.txt`（内容："hello backup and restore verification"）；
   - 为生成的新 Node ID 写入元数据 `NodeMetadata(tags = ["backup", "verified"], description = "backup test note")`；
   - 调用 `vfs1.close()` 正常关闭实例；
   - 模拟离线冷备份：将 `state.db`（及伴随的 wal/shm 文件）和物理文件复制到临时备份目录；
   - 模拟原环境物理损坏：物理删除原目录下的 `state.db` 和 `backup_test.txt`；
   - 从备份介质恢复：将备份的数据库文件及物理文件回拷至原路径；
   - 原配置重新启动 VFS 实例 `vfs2`；
   - 执行核验：
     - `stat(uri).id` 严格等于 `origId`；
     - `read(uri)` 内容严格匹配原始字符串；
     - `getMetadata(origId)` 的 Tags 和 Description 完整无损。
2. **实测结果**：**全步骤验证通过（PASS）**。成功证明在遵循正常关闭与原挂载身份路径的约束下，离线备份与恢复机制完全有效。
