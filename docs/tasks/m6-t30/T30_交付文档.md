1. **发布状态诚实性**：明确当前仍处于源码工程内调用阶段，不虚构 Maven / Gradle 坐标或远端依赖，独立产物消费留至 T31。

4. **状态库与离线备份**：明确 SQLite 状态库为持久真理源；首版仅提供并在隔离环境验证了“正常关闭 -> 离线复制库与数据 -> 原路径重开核验”冷备份方案，不承诺在线快照或自动崩溃修复。
