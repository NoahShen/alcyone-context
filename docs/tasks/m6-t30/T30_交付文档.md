## 3. 设计取舍与边界说明

1. **发布状态诚实性**：明确当前仍处于源码工程内调用阶段，不虚构 Maven / Gradle 坐标或远端依赖，独立产物消费留至 T31。
2. **平台支持边界保持**：仅对 macOS arm64 提供已验证支持承诺；Linux 配置保留但声明未验证；其余平台由工具链脚本显式拒绝。
3. **方案④约束贯彻**：文档明确告知调用方底层 native 请求无全局超时强杀保证，`closeGracePeriod` 仅为协作取消期限，禁止外部线程强杀。
4. **状态库与离线冷备份**：明确 SQLite 状态库使用标准单连接（DELETE 模式），正常关闭后仅存在单文件 `state.db`；首版仅提供并在隔离环境验证了“正常关闭 -> 离线复制库与数据 -> 原路径重开核验”冷备份方案，不承诺在线快照或自动崩溃修复。
