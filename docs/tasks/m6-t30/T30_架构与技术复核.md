### 6.4 必须修改：R4 冷备份证据仍不成立

验收 §2 指定 `RuntimeReopenIdentityTest`，并声称该命令执行了 PRAGMA、文件清单检查、离线复制、删除原库、回拷恢复。逐行核对该类两个用例及 withVfs/query/prepare 辅助方法后，事实如下：

| 声称 | 源码实际行为 |
| --- | --- |
| 查询 journal_mode=delete | 无 PRAGMA journal_mode 查询 |
| 检查 wal/shm/journal 不存在 | 无相应 Files.exists 或目录清单断言 |
