## 2. 文档编写内容

### 2.1 README 与接入现状

明确 Alcyone Context 项目当前已交付的是 VFS SDK，隐藏 Local FS / WebDAV 的数据访问细节；Memory、Git Sync 等规划不能写成已完成能力。给出项目内 bootstrap、样例、常规检查及真实 WebDAV 检查入口，区分“源码工程内调用”与尚待 T31 验证的独立产物消费。

例：可引用现有 `LocalFsSampleTest` 的 Gradle 运行命令，不能凭空写 Maven 坐标、版本、远端仓库地址或“已发布”。本阶段仅 macOS arm64 已验证支持，Linux x64 / arm64 配置保留、未验证，其余平台按当前脚本拒绝。

### 2.2 配置、Mount 与 Context System 分工

按实际 `VfsRuntimeConfig`、`MountConfig`、`MountBackend.LocalFs / WebDav` 说明状态库位置、已存在的本地根、命名空间、storageKey、endpoint / root、凭据与限额。解释逻辑路径与后端相对位置、挂载重叠 / 身份冲突和重开约束，不要求调用者手工创建 Operator / Driver / Repository。

例：Context System 给 Agent A 使用 `/resources/agent-a`，这是上层的目录约定；VFS 不绑定 Agent 身份、不做 ACL，也不会阻止持有整个 VFS 实例的调用者访问其他合法目录。凭据由宿主注入，示例只使用测试值或环境变量，不打印密码、不写入 URI userinfo。

### 2.3 核心操作、身份与 Metadata

覆盖 read / stat / getNode / list、三种写模式、文件与目录移动、非递归 / 递归删除、Metadata 查询与整体替换，讲清 Node ID 与 URI 的区别。列出后端能力和 Core 编排的关系：原生文件 move、复制回退、跨后端目录移动不能混成一张“支持 / 不支持”表。

例：read / list 不登记，stat 可懒注册；移动保留 ID / Metadata，删除后同路径重建为新 ID。`includeStorage=false` 对已登记节点走逻辑查询，对未登记物理资源仍确认存在；补父目录不单发事件，覆盖写产生 FILE_WRITTEN，Metadata 同值成功更新仍发事件。

### 2.4 流、事件与关闭

给出 `openStream(...).use { result -> ... }` 的分块读取示例，避免示例再次把大文件全部读入内存；关闭完整 result，Runtime 放在 try/finally 中调用挂起 close。说明订阅先于目标操作、状态与事件同事务后通知、普通 Consumer 异常隔离、慢 Consumer 的影响和队列丢弃，不承诺重试 / ACK / 重放。

例：等待通知的样例用事件身份 / 目标与类型或明确的单目标条件，不用 sleep；订阅取消与宿主取消不能统一写成普通业务失败。关闭会停止接纳并等在途清理后释放，方案④保持：closeGracePeriod 不等于 close 或 native 请求最长耗时，不建议强杀线程释放 native。

### 2.5 错误、部分失败与诊断

说明 `VfsException` 的 code / effect / cause 与 CancellationException 的区别；按预检、物理阶段、逻辑提交阶段解释失败，复用 T23～T29 已验证事实。诊断例子仅展示受管信息和测试数据，生产日志绑定由宿主提供，不承诺任意 Consumer 字符串自动脱敏。

例：目标已写而删源失败时可能两边都有文件，UNKNOWN 不能擅自改成 NONE / PARTIAL；不能捕获异常后无条件重试整个 move 或宣称磁盘已回滚。取消不证明操作未提交，自动修复与崩溃恢复仍延后。

### 2.6 状态库维护与离线备份

明确 SQLite 保存身份、路径、Metadata、Mount 和事件，不是可随意删除的缓存；正常重开需要匹配挂载配置，独占冲突不能靠删除锁文件绕过。首版给出离线流程：暂停上层写入并排除外部变更、正常关闭实例且确认成功、按实际 SQLite 文件布局复制状态库与相关文件内容、保留匹配配置，再在隔离位置验证副本重开。

例：仅备份 SQLite 不等于备份本地 / WebDAV 文件，也不是跨后端原子快照。若发现 journal / WAL 等伴随文件或关闭失败，不建议只复制主库或手工删除伴随文件；先查当前实现和数据库状态，文档仅承诺已验证的正常关闭离线场景，不新增在线备份 API、迁移或崩溃恢复机制。
