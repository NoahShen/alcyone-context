### 2.1 Storage 边界

```kotlin
enum class StorageWriteMode { CREATE_NEW, REPLACE_EXISTING, UPSERT }

data class StorageAttributes(
    val type: NodeType,
    val sizeBytes: Long? = null,
    val modifiedAt: Instant? = null,
)

data class StorageEntry(
    val name: String,
    val type: NodeType,
    val attributes: StorageAttributes? = null,
)

class StorageContent(val bytes: ByteArray, val attributes: StorageAttributes)

interface StorageStream : AutoCloseable {
    val attributes: StorageAttributes
    fun openStream(): InputStream
}

data class StorageCapabilities(
    val nativeFileMove: Boolean = true,
    val nativeDirectoryMove: Boolean = true,
    val createDirectory: Boolean = true,
    val boundedRead: Boolean = true,
)

interface Storage {
    suspend fun read(path: StoragePath, maxBytes: Long): StorageContent
    suspend fun readStream(path: StoragePath, maxBytes: Long? = null): StorageStream
    suspend fun stat(path: StoragePath): StorageAttributes
    suspend fun list(path: StoragePath): List<StorageEntry>
    suspend fun write(path: StoragePath, content: ByteArray, mode: StorageWriteMode): StorageAttributes
    suspend fun createDirectory(path: StoragePath)
    suspend fun move(source: StoragePath, target: StoragePath): StorageAttributes
    suspend fun delete(path: StoragePath, recursive: Boolean)
    fun capabilities(): StorageCapabilities
}
```

`StoragePath` 关键语义：挂载根是 `segments` 为空的独立表示（不用空字符串），规范相对文本为 `.`；输入已解码，`parse` 不做百分号解码；拒绝绝对路径、空中间段、`.` / `..`、段内 `/` 与 `\`、C0/DEL/C1 控制字符、孤立代理字符；不可变（入参防御性拷贝 + `Collections.unmodifiableList`）。

### 2.2 状态边界

```kotlin
data class NodeRecord(
    val id: NodeId,
    val path: VfsPath,

data class MountRecord(

data class EventRecord(

interface NodeRepository {

    suspend fun updatePath(id: NodeId, newPath: VfsPath, updatedAt: Instant)
    suspend fun touch(id: NodeId, updatedAt: Instant)
    suspend fun markDeleted(ids: Collection<NodeId>, deletedAt: Instant)
    suspend fun findSubtree(path: VfsPath): List<NodeRecord>

interface MetadataRepository {

    suspend fun delete(id: NodeId)

}

```

### 2.3 事务与通知边界

```kotlin
interface TransactionScope {
    val nodes: NodeRepository
    val metadata: MetadataRepository
    val events: EventRepository
}

interface UnitOfWork {
    suspend fun <T> inTransaction(block: suspend (TransactionScope) -> T): T
}

fun interface VfsEventConsumer {
    suspend fun onEvent(event: VfsEvent)
}

class EventDispatcher {
    fun subscribe(consumer: VfsEventConsumer)
    suspend fun dispatch(events: List<VfsEvent>)
}
```

`EventDispatcher` 是 **Core 内部组件**，不是 Storage 或 Repository 的方法。异常处理契约（本轮修复后）：`CancellationException` 原样传播；其余 `Exception` 记录日志后继续分发；`Error` 不捕获，按原义上抛。

## 5. 六个设计问题的裁决结论

前次交付提出的 6 个问题，复核第 3 节已逐条给出处理意见。本轮据此执行，结论如下：

| 问题 | 裁决 | 归属 |
| --- | --- | --- |
| 1. 父路径为文件的错误码 | 按条件式修订：实现能确认文件/目录冲突时 `TYPE_MISMATCH`，无法识别原因的 I/O 失败用 `STORAGE_ERROR`，不要求额外探测。T02 §11 W04 在可确认类型冲突时继续成立 | T12 实现验证 |
| 2. 流式约束是否由类型强制 | 不强制。公开计数器不能保证限额。接口补充 `maxBytes=null` 含义、限额约束实际读取内容、返回资源由调用方关闭 | T12 实现与测试 |
| 3. 软删除是否写入 KDoc | 写入最小语义：删除后正常查询不返回该节点、有效路径可被新节点复用。`NodeRecord` 仍只表示有效节点。**不在 T07 追加数据库字段、存储方式或事务实现约束** | T11 |
| 4. 提交后通知是否强制成对封装 | 接受分离接口，本轮不增加协调器。**T14 / T15 必须通过编排测试证明**：仅在提交成功后通知、提交失败不通知、通知失败不改已提交结果；不能仅验证一份手工置空的事件集合 | T14 / T15 |
| 5. A06 是否移出 | 记为**不适用**。T07 无时间/ID 生成流程。Node 生成与时间字段在 T13 验证，事件在 T14 验证，保留现有 UUID 工具测试 | T13 / T14 |
| 6. 是否补三个能力字段 | 本轮不扩充。符号链接、文件名限制、递归删除的支持判定与检查步骤留 T10 / T12，以实际用例决定是否需要补接口 | T10 / T12 |

**另需注意**：公共流式方法方向已在 T01 记录，但 `Vfs` 尚无对应方法。**不把 `StorageStream` 当作公共 API 已交付**。T15 / T18 的任务验收应覆盖公共签名、调用方关闭责任和有效限额配置，具体签名仍按已记录流程确认。

## 8. 未验证事项

以下均为**本任务未验证**，不得当作已通过：

1. **替身不是真实 SQLite 事务**（T11）。`FakeStateUnitOfWork` 用写时复制实现提交与回滚，只证明"一次提交内的可见性与回滚边界"，不证明 SQLite 的原子提交、隔离级别或崩溃恢复。
2. **替身不是真实文件系统 I/O**（T12）。`StorageFakeImpl` 用 `Map<String, Node>` 模拟目录树，不含 OpenDAL Operator、后端能力差异、符号链接与物理根边界。
3. **流式读取的真实执行未验证**（T12）。`StorageStream` 只有接口与替身行为；读前 stat 快速拒绝与读取中逐块计数中止的两层防护需在 OpenDAL 上验证。
4. **事件未持久化、未重放**（T14 / E05）。`EventRepository.append` 只有内存实现；无事件表、无消费游标、无重启重放。
5. **事务提交后才通知未被编排测试证明**（T14 / T15）。当前只用"提交失败时可分发集合为空"间接演示，复核已要求后续用编排测试实际证明。
6. **操作中断与重启恢复未实现**（E04，首版不做）。
7. **非 macOS arm64 平台未验证**。仅在 macOS arm64 + Temurin 21.0.12.1+1 验证。
8. **Maven 发布坐标未配置**（T31）。根 `build.gradle.kts` 仍无 `group` / `version`。
9. **Node SQLite schema 未定义**（T11）。`markDeleted` 的 `deletedAt` 在替身中被忽略，删除标记的数据库实现留 T11。
10. **`StorageFakeImpl` 的已知简化**：`move` 不校验跨挂载根（T21 编排）；`list` 返回顺序取决于 `Map` 迭代顺序（T02 明确无排序保证）。
