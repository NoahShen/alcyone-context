## 6. 未验证事项

以下均为**本任务未验证**内容，不得当作已通过：

1. **替身不是真实 SQLite 事务**（T11）。`FakeStateUnitOfWork` 用写时复制实现提交与回滚，只证明「一次提交内的可见性与回滚边界」，不证明 SQLite 的原子提交、隔离级别或崩溃恢复。
2. **替身不是真实文件系统 I/O**（T12）。`StorageFakeImpl` 用 `Map<String, Node>` 模拟挂载根内的目录树，不含 OpenDAL Operator、后端能力差异、符号链接与物理根边界。
3. **事件未持久化、未重放**（T14 / E05）。`EventRepository.append` 只有内存列表实现；无事件表、无消费游标、无重启重放。
4. **流式读取未在真实后端验证**。`StorageStream` 只有接口与替身行为（`InputStream` 逐字节计数）；读前 stat 快速拒绝 + 读取中逐块计数中止的两层防护（G4）需 T12 在 OpenDAL 上验证。
5. **操作中断与重启恢复未实现**（E04，首版不做）。T03 第 8 节的恢复日志、补偿与断点续做均未开始。
6. **非 macOS arm64 平台未验证**。本任务仅在 macOS arm64 + Temurin 21.0.12.1+1 验证；Windows / Linux 及 x86_64 未验证，OpenDAL native classifier 与 SQLite 驱动加载未在那些平台验证。
7. **Maven 发布坐标未配置**（T31）。R0 只统一了包名；根 `build.gradle.kts` 仍无 `group` / `version` 与发布配置，`com.github.NoahShen` 的 Maven 坐标尚未真正建立。
8. **Core 业务编排未实现**（T15 / T16 / T20～T23）。九个公共用例的 `Vfs` 方法体、Mount 路由（T09）、Node Registry 与懒注册（T13）、能力检查与降级（T10）均未实现；本任务只交付 Port 契约与状态类型。
9. **提交后分发的编排决策未固化**。「提交成功才分发」目前靠调用方遵守契约，测试用「提交失败时可分发集合为空」间接演示；未提供 `UnitOfWork` 与 `EventDispatcher` 的成对封装，避免提前锁死 T15 的编排形态。
10. **A06 本轮不适用**。按 B1 决议不建可注入时钟 / ID 生成器，且本任务没有时间与 ID 的填充逻辑，无可验证对象。UUIDv7 格式校验仅在测试数据构造时使用，未验证 Core 侧生成路径；Node 与时间字段归 T13，事件归 T14。

## 7. 遗留问题（均已确认留到后续任务处理）

1. **`vfs/api` 在 git 中呈现为「删除 + 未跟踪新目录」**。R0 改名把 17 个文件从 `vfs/api/src/main/kotlin/*.kt` 移到 `vfs/api/src/main/kotlin/com/github/noahshen/alcyone/context/vfs/`，`git status` 因此显示 13 个 `D` 加 4 个 `D`（测试）与 `?? vfs/api/src/main/kotlin/com/`。这是路径移动的结果，不是删除文件；提交时应由 git 的重命名检测识别，**不要**按删除处理。
2. **`StorageFakeImpl` 的 `move` 未校验跨挂载根**。替身把整个 `Map` 当单个挂载根，`move` 只处理同一 Storage 内移动；跨挂载复制（读→写→确认→删）需 T21 编排，不属本任务。
3. **`StorageFakeImpl` 的 `list` 返回顺序取决于 `Map` 迭代顺序**。当前 B3 用例只断言条目集合，未断言顺序；若后续需要稳定顺序，应在 T12 或业务实现任务统一处理。
4. **`markDeleted(ids, deletedAt)` 的 `deletedAt` 参数在替身中被忽略**：`NodeRecord` 无删除时间字段，参数已收但不存。T07 决定将 Node SQLite schema 与删除标记策略留到 T11 实现时一并定义——首版 T03 §2 只要求"删除后旧 ID 查询返回 NOT_FOUND"，事件表里已有 `FILE_DELETED` 事件携带 `occurredAt`，删除时间本身不会丢。**暂不改契约、不改代码**。若 T13 需要保留删除时间以支持审计或恢复，届时再评估是否扩 `NodeRecord`。
