## 1. 目标与范围

支持普通目录同 Mount / 跨 Mount 移动，包含空目录；成功后根及全部已登记子 Node 保持 ID、Metadata 与 registeredAt，未登记后代不因遍历而批量注册。复用 Core、Guard、Storage、Repository 和 EventPipeline，公开 move 签名不变，不新增恢复日志、目录管理器或复制任务框架。

例：把包含 `a.txt`、`images/b.png` 和空目录 `drafts/` 的 `work/` 移到 `archive/work/`，实际树完整保留；已登记 a.txt 的 ID 随路径迁移，未登记 b.png 仍只存在于物理树。WebDAV、流式写入、外部任意并发协调和崩溃恢复不在本任务；更广的故障组合留 T23。

## 2. 开发内容

### 2.1 预检与策略

先确认源实际类型，再按 Guard 选择原生目录移动、同 Mount 复制回退或跨 Mount 复制；目录自身、目标落入源子树、已有目标、只读及配置目录保护沿用既有规则。源树含嵌套 Mount、目标路径将包含已配置 Mount 时，在登记源和物理变更前拒绝；已有目标目录不能当作“移入其中”或合并目录树。

例：`work → work/sub` 报参数冲突，`work` 内挂了另一块盘则拒绝整个移动。当前 Local FS 的 `nativeDirectoryMove=false`，同 Mount 真栈也走复制回退；能力声明支持原生目录移动的分支可用受控 Storage 验证，不改后端能力值来伪造支持。

### 2.2 整树复制、空目录与确认

通过 Storage.list 遍历实际目录，记录相对路径、类型和可用属性，显式创建目标根及空子目录；逐文件复用 T21 的有界读取、源侧提前检查、CREATE_NEW 和目标确认，不能调用公开 Vfs 操作拼流程。整树所有条目完成复制和确认后才开始删源，核对目标条目集合 / 类型与各文件可用长度；发现已知源集合或长度变化报 CONFLICT，不将长度一致说成哈希一致。

例：第一份文件已复制、第二份文件读取失败，整个源树保持，目标允许留部分内容；不能复制完第一份就删第一份。用有限缓冲逐文件处理，不把整树文件内容一次装进内存；单文件继续受 T21 限额约束，后面的文件超限时须报告前面已发生的复制副作用。

### 2.3 子树身份与路径更新

源根若未登记，只为根建立 DIRECTORY 身份，已登记后代由 findSubtree 按完整段边界选取，并把源前缀替换成目标前缀；不要沿用文件专用注册助手生成 FILE 根，也不重新生成子 Node ID。移动完成后在同一事务中更新根与全部有效已登记后代的路径 / 时间，保留 Metadata，不批量登记未注册后代或删除原记录再重建。

例：`a/x.txt → b/x.txt` 迁移，`a-old/keep.txt` 和 `A/keep.txt` 不动；根未登记但 x.txt 已登记也必须正确处理。物理树与逻辑子树分别取数，不能仅移动磁盘遍历时偶然见到的已登记项；遇到状态唯一约束冲突走状态失败，不覆盖另一 Node 来凑成功。

### 2.4 串行、事务与目录事件

沿用单次 StateBoundary 覆盖预检、必要注册、复制 / 原生移动、删源和提交；SQLite 事务只包全部路径更新及一条 DIRECTORY_MOVED，提交后才通知。首版目录移动只发根级事件，nodeId 为源根身份、uri 为目标根、sourceUri / targetUri 为源 / 目标根，表示整棵子树路径已迁移，不额外发子文件移动或复制产生的创建 / 删除事件。

例：移动包含 20 个已登记文件的目录，库里更新根和 20 个子 Node，但仅一条 DIRECTORY_MOVED；Consumer 按完整段边界处理子树路径变化。将此粒度和 Consumer 含义回写 T01 §8 / T02 §7.2，不增加事件字段；源 / 目标属性直接用已有结果，不为返回 NodeInfo 再查一轮后端。

### 2.5 失败与取消

树复制或确认未完成时不开始任何源删除；删源阶段可能部分失败，此时目标完整、源可能残缺，保留原逻辑映射、不发整体成功事件，也不自动回删目标或补回源。整树物理移动成功但状态更新 / 事件失败报 STATE_ERROR + PARTIAL、保留 cause，事务回滚全部逻辑路径；原后端错误码与 UNKNOWN 沿用 T21，不因已复制文件而降级。

例：第二个子 Node 更新失败，根及第一个子 Node 的数据库路径也必须回滚，物理目录不回移。CancellationException 原样传播，至少验证复制尚未完成时取消会停止后续复制 / 删源 / 成功提交并释放边界；只认已观测事实，不扩大成所有取消窗口保障。

### 2.6 真实栈与文档承接

公开 Runtime + 真 SQLite + 临时 Local FS 验证同 Mount 回退与跨 Mount 树移动、空目录、身份及正常重开，状态库放在挂载根外；精确故障和原生策略用包装 / 替身并明确分层。符号链接与物理路径约束复用 T12，不通过 JDK 直读写绕过 Storage。

例：同一份样例树同时包含已登记文件、未登记文件和空目录，移动后核对实际树与状态库记录数。更新 T18～T21 当前使用说明和测试中“目录仍不支持”的阶段口径，保留历史结论与嵌套 Mount 等仍有效的拒绝断言。

## 4. 验收标准

| 编号 | 必须满足 | 核心证据 |
| --- | --- | --- |
| A01 目录移动闭环 | 同 Mount、跨 Mount 普通目录均成功，嵌套文件与空目录不丢；原生策略不误走复制 | 公开 Runtime 真栈两种移动，比较相对路径 / 类型集合与内容；空根或空子目录代表用例；受控原生能力分支；T20 / T21 文件回归 |
| A02 身份与子树边界 | 根 / 已登记后代 ID、Metadata、registeredAt 保留，未登记后代不批量注册，重开稳定 | 根已登记与“根未登记、子已登记”；a / a-old / A 及带下划线段边界；移动后的原 ID 查询与状态记录数 |
| A03 预检与挂载保护 | 同路径、自包含、目标已存在、含嵌套 Mount、目标含已配置 Mount、只读及目录创建能力不足按契约拒绝 | 代表反例断无注册 / 物理变更 / 成功事件；Guard 既有纯逻辑矩阵可引用，必须有目录编排接线证据 |
| A04 整树确认先于删源 | 所有文件与空目录复制并确认后才允许任何源删除；中途读 / 写 / 确认或后续文件超限不提前删源 | 多条目受控顺序；至少一个前项成功后后项失败、一个条目集合 / 类型不符，断整棵源保持、目标残留与 effect；复用 T21 长度和限额机制 |
| A05 状态与事件原子性 | 全部逻辑路径与一条 DIRECTORY_MOVED 同事务，提交后通知，无子项成功事件 | 真 SQLite 正常记录与字段；至少一次已更新部分 Node 后抛错或事件冲突，核对所有原路径 / Metadata 回滚、无日志 / 无成功通知，物理不补偿 |
| A06 部分失败事实 | 补目录 / 已复制部分目标 / 部分删源 / 状态失败均如实报告，原码与 UNKNOWN 保留 | 受控部分删源失败：目标完整、源残缺、逻辑映射仍在源、无整体成功事件；已变更不能回报 NONE，UNKNOWN 不降级；不伪称真实磁盘故障 |
| A07 锁与取消 | 整树全链单锁、不重入；复制阶段取消原样传播，停止后续动作、释放边界 | 最小受控相遇与已进入复制后的取消，协程内捕获实际异常，断源 / 目标事实与后续可用；finally 放行并等工作收尾后再关资源 |
| A08 工程与交付 | 681 例基线无回归，目录事件 / 阶段说明回写，无无关扩张 | 项目内完整检查、源码与 XML 计数、真实双 Mount 目录样例、各项证据归属和未验证边界 |

一个用例可覆盖多项；复用已有组件证据，新增重点是“整树复制完成后删源”和“全部逻辑路径同事务迁移”。不要求固定变异数量或连续运行次数，不把源盘内容未变与源 delete 从未被调用混为一种证据。
