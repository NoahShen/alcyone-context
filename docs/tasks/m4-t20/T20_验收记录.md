### A03 预检与阶段边界

| 场景 | 期望 | 实测 | 分层 |
| --- | --- | --- | --- |
| 同路径 move | `INVALID_ARGUMENT` | ✔ | 替身 + 公开 Runtime |
| 目标落进源子树 | `INVALID_ARGUMENT` | ✔ | 替身 |
| 缺失源 | `NOT_FOUND` | ✔ | 替身 + 公开 Runtime |
| 目标已存在（文件 / 目录） | `ALREADY_EXISTS` | ✔ | 替身 + 公开 Runtime |
| 受保护配置目录（源或目标） | `UNSUPPORTED_OPERATION` + `NONE` | ✔ | 替身 + 公开 Runtime |
| 目录移动 | `UNSUPPORTED_OPERATION` + `NONE` | ✔ | 替身 + 公开 Runtime |

拒绝类用例均断言**无 `move:` 调用、无事件、源 / 目标内容不变**。不复制 T10 完整策略矩阵，只钉本任务编排路径；
Guard 策略证据与本轮编排拒绝证据分两行，不混为一谈。
