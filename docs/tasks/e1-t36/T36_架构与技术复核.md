## 4. R3：测试/消费Git辅助进程缺少有效超时与清理

两处helper先 `inputStream.readAllBytes()` 再waitFor(timeout)，读取可无限阻塞，后面的超时不能保护它；消费bare init直接无界waitFor。远端检查也同样先读流。超时未销毁/确认本次进程，错误路径可能留后台资源。顶层JUnit Timeout不能代替底层阻塞读取和资源回收。

改为能同时排空输出和有界等待的简单测试辅助方式（例如受控临时输出重定向+waitFor），在失败/超时finally仅清理本次创建进程，检查所有退出码。测试装置隔离Git全局配置、身份/签名/hooks等影响，不修改宿主配置；不把测试隔离设置注入生产。复用已有工具模式，不造通用进程框架。
