## 1. 目标与范围

在 `vfs/api` 中实现 T01 已审阅通过的公共类型与接口，并把 T02 第 2 节的路径规范化规则落成可执行代码和测试。类型与接口必须真实编译、路径解析必须有针对性测试。

## 4. 必须落地的路径规则

T02 第 2 节规则以代码和测试体现，测试至少覆盖第 2.3 节全部例子：

| 规则 | 行为 |
| --- | --- |
| 接受空间 | `alcyone://` → `/`；`alcyone://memory/` → `/memory`；`alcyone://resources` → `/resources`；scheme 不区分大小写并统一输出 `alcyone` |
| 命名空间 | 不限制第一段名称；所有路径段保留大小写，不查询 Runtime 配置 |
| 拒绝项 | userinfo、端口、query、fragment；`//` 内部连续分隔符；段内 `%` 解码后为 `.` / `..`；段内含 `/`、反斜线、NUL、控制字符；原始反斜线 |
| 解码 | 每段严格 UTF-8 百分号解码一次，不折叠大小写、不做 Unicode 归一化、不 trim；原始空格必须写 `%20` |
| 幂等 | `VfsUri` → `VfsPath` → `VfsUri` 结果稳定；`/resources/a` 与 `/resources/a/` 是同一逻辑位置 |
| 序列化 | 逐段编码，保留 unreserved 字符，其余 UTF-8 百分号编码且十六进制大写；任意单段路径对应的 URI 输出尾斜线，`isNamespaceRoot` 仅表示结构 |

`VfsPath` 的直接构造输入是已解码路径，执行相同的段边界检查，但不解码字面百分号。非法输入在本地被拒绝，不触发 Mount 或 Storage；本任务不涉及任何 I/O。

删除 `VfsProtocol.NAMESPACE_SEGMENTS`、对应成员检查及 `first segment must be 'memory' or 'resources'` 错误描述；保留 `SCHEME` 和路径语法检查。验收须覆盖 URI / Path 的自定义第一段、大小写保留及单段路径规范化，详见 [修复清单 R5](T06_复核与修复清单.md)；本任务不提前实现配置注入。

## 5. 本任务不做

- 不实现 `Vfs` 的任何方法体；接口只声明签名。
- 不引入 Mount、Storage Path、Operator、Driver、Repository 或 `VfsConfig`；事件订阅入口属于 T18。
- 不新增 `mkdir`、分页、流式读写或 `MoveOptions`；T01、T02 未纳入首版的接口不补。
- 不改其他五个模块的构建配置，不改 `scripts/dev`、Wrapper、根 `build.gradle.kts` 或 `.gitignore`。
- 不改设计文档的契约；若发现契约缺口或矛盾，在本文件或对应设计文档记录决策后再实现。
