## 1. 构建与测试

在 macOS arm64 使用项目内工具链，命令与 T05 相同，不改系统 JDK、Gradle 或 shell 配置：

```sh
./scripts/dev bootstrap                      # 首次或工具链校验失败时执行
./scripts/dev gradle clean build --console=plain
./scripts/dev gradle :vfs:api:test --console=plain
./scripts/dev gradle -q javaToolchains       # 确认测试使用项目 JDK 21
```

诊断用命令：

```sh
./scripts/dev gradle :vfs:api:dependencies --configuration runtimeClasspath --console=plain
./scripts/dev gradle :vfs:api:test --console=plain --info --rerun-tasks
.local/jdk/jdk-21.0.12.1+1/Contents/Home/bin/javap -p -cp vfs/api/build/classes/kotlin/main alcyone.vfs.Vfs
```

原始日志与用例清单位于 `.local/tmp/acceptance/t06/`（`clean-build.log`、`api-test-info.log`、`api-deps.log`、`api-signatures.log`、`test-cases.txt`），该目录被 Git 忽略，不随提交保存。

- 路径：`VfsUri.kt`（解析、规范化序列化）、`VfsPath.kt`（已解码逻辑路径、段校验、段列表与根表示）。

- 测试：`VfsUriTest`、`VfsPathTest`、`NodeIdTest`、`PublicContractTest`，共 46 个用例。
- `vfs/api/build.gradle.kts` 增加 `testImplementation(libs.kotlin.test)`、JUnit BOM、`testRuntimeOnly` engine 与 launcher，写法与 `integration-tests/vfs/build.gradle.kts` 一致。

使用示例：

```kotlin
val uri = VfsUri.parse("alcyone://resources/medical/a%20b.dcm")  // 非法输入抛 VfsException(INVALID_URI)
val path: VfsPath = uri.path                                      // /resources/medical/a b.dcm
val id = NodeId.parse("018f6a3c-9c1e-7b2d-8f3a-4c5d6e7f8091")     // 只校验 UUIDv7 文本，不生成
```

## 3. 实现中明确的细节

以下未在 T01 / T02 单独规定，按已审阅规则取最保守解释；后续任务如需改变，直接改代码并回写文档。

| 事项 | 本次实现 | 依据 |
| --- | --- | --- |
| 原始空格 | URI 输入中出现未编码空格即 `INVALID_URI`；文件名中的空格必须写 `%20` | T02 2.2 规则 4“原始空格要求使用 `%20`” |
| 非首段的 `:` / `@` | 仅拒绝第一段的 `:` 与 `@`（端口、userinfo 位置）；其他段的 `:` 合法，序列化时编码为 `%3A` | T02 2.2 拒绝项只列端口与 userinfo |
| 原始非 ASCII 字符 | 接受并按 UTF-8 逐字节解码，与 `alcyone://resources/报告.md` 例子一致 | T02 2.3 例子 3 |
| 路径类错误的 code | `VfsUri.parse` 与 `VfsPath.parse` 的格式错误统一为 `INVALID_URI`；`NodeId` / `VfsEventId` 格式错误为 `INVALID_ARGUMENT` | T01 第 7 节把 URI 与 ID 分列在同一行，实现按入口分类 |
| `VfsEffect` 默认值 | 构造默认为 `NONE`；存储写入、跨 Mount 移动等操作在实现时必须显式传 `PARTIAL` / `UNKNOWN` | T01 7.1“effect 不能仅由错误码猜测” |
| 异常消息内容 | 只含拒绝原因，不回显原始输入，避免文件名或凭据进入日志 | T01 7.1 诊断信息限制 |
