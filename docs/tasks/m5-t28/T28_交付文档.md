## 1. 交付范围

本次任务以**平台支持现状核查、native 选择严密性、诊断上下文与凭据保护核查、排障指南整理**为主，严格遵循最小修复原则：
1. **平台矩阵真实建档**：严格区分五类证据（工具链配置、native 依赖解析、真实运行、常规回归、真实 WebDAV），macOS arm64 两套实跑通过，Linux x64 与 Linux arm64 如实列明未实跑与阻塞条件，不伪造通过。
2. **选择一致性与兜底修复**：消除 OpenDAL classifier 将未知 OS/CPU 静默落入 `linux-x86_64` 的安全隐患，改为白名单映射 + 抛错拒绝；配套单元测试。
3. **诊断上下文与日志捕获**：系统化归纳六类诊断入口（操作、后端、Mount、资源、code、effect、cause、事件 ID），增加 SLF4J 生产只依赖 API 前提下的测试日志捕获验证。
4. **全链路凭据保护审查**：覆盖配置 `toString()`、身份串、数据库持久表、异常链（cause / suppressed / stacktrace）、日志输出，确保凭据不泄露。
5. **排障指南与证据归档**：在《T28 使用说明》中提供 6 种常见故障排查步骤与清晰的可复现诊断路径。

## 4. 平台与诊断核查结论

1. **macOS arm64**：当前唯一完全实测平台。Temurin JDK 21.0.12.1+1、OpenDAL 0.50.6 native（osx-aarch_64）、SQLite JNI、WsgiDAV 4.3.3 网络闭环全部实测通过。
2. **Linux x64**：工具链与构建配置就绪，CI 曾于历史 T08 验证过基础构建；当前完整 VFS Adapter 与真实网络测试尚未在远端实跑，结论单列交复核确认。
3. **Linux arm64**：工具链与构建配置就绪，无真实 ARM 运行环境，明确列为未实测。
4. **诊断能力**：异常链保留完整上下文与根因；异步通知日志包含事件 ID；生产未捆绑任何日志实现框架。
5. **凭据安全**：经多重反例核验，密码与 userinfo 在配置文本、数据库存储、异常输出与日志中均安全脱敏。
