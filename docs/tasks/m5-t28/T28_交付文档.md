## 4. 平台与诊断核查结论

1. **macOS arm64**：当前实测通过平台。Temurin JDK 21.0.12.1+1、OpenDAL 0.50.6 native（osx-aarch_64）、SQLite JNI、WsgiDAV 4.3.3 网络闭环实测通过。
2. **Linux x64**：工具链与构建配置就绪，当前交付版本尚未在目标机实跑；状态为“待当前实跑验证 / 配置就绪”。
3. **Linux arm64**：工具链与构建配置就绪，缺少真实 ARM 环境与 runner 阻塞；状态为“待验证 / 缺少硬件 runner”。
4. **macOS x64 与其他平台**：`scripts/dev` 与 `vfs/storage/build.gradle.kts` 统一显式拒绝，绝不静默兜底。
5. **诊断能力**：异常链保留完整上下文与根因；异步通知日志包含事件 ID 与 WARN 级别；生产未捆绑任何日志实现框架。
6. **受管凭据保护**：经多重反例核验与真实端到端测试，受管 WebDAV 凭据（密码与 userinfo）在配置文本、数据库存储、真实认证异常链（涵盖 message / toString / cause / suppressed / stackTraceToString 完整文本）及实际捕获日志中均得到有效保护，不发生泄露。A05 已由 8407ce1 独立复核确认关闭。
