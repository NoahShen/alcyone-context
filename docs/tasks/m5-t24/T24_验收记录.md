## 3. 失败观察与实测记录

以下都是**观察到的**后端行为，写进实现与文档时如实标注了来源：

| 现象 | 实测方式 | 处理 |
| --- | --- | --- |
| HTTP 401 被 OpenDAL 报成 `Unexpected`，消息里带 `status: 401` | jshell 直接打 OpenDAL `webdav` 服务（探针，非交付用例） | `mapStorageErrors` 按 `status: 401` 认成 `STORAGE_ACCESS_DENIED`；交付文档写明这是按观察行为写的对照 |
| 删除不存在的目标 / 删除非空目录 / 列不存在的目录，后端都可能「成功」 | 同上 | Adapter 各自先 `stat`、非递归删先列一层 |
| `createDir` 必须以 `/` 结尾 | 同上 | `dirPath()` 统一补尾斜杠 |
| 目录子项的 list 路径带结尾 `/`（`t24-loop/报告/`） | 首次真实闭环跑挂 → 修 `listChildren` 后通过 | 切前缀后去掉尾 `/`，再要求「恰好一个段」 |
| 打开一个不存在的 OpenDAL `root`，`stat("")` 也报 `DIR` | 同上 | 因此**不做**打开时的根探测（既查不出、还可能让服务器建目录） |
| 不可达端口：本机观察到先经过本地代理拿到 502，OpenDAL 报 `Unexpected` | jshell 探针 + `A05` 真实用例 | 用例只断言「是 `VfsException` + 30 秒内 + 无凭据」，不锁死具体错误码（拒绝连接与代理 502 走的是不同后端分支） |

**变异**：本轮未执行变异；不把开发方说明当成独立变异结果。
