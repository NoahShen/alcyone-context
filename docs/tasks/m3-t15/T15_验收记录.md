## 3. A01～A08 逐条结论

| 项 | 结论 | 证据（core 替身层 / integration 真实栈） |
| --- | --- | --- |
| A01 查询与限额 | 通过 | read 不注册（core `an unregistered file can be read and reading it registers nothing`）；stat 首次给身份、后续复用（core + 真实栈）；includeStorage=false 不碰后端；限额 = min(配置, maxBytes)，0 只接受空文件 |
| A02 写入语义 | 通过 | 三模式矩阵按实际存在性执行（core `the mode matrix is enforced on the real existence of the target`）；覆盖预存未登记文件报 FILE_WRITTEN（真实栈 `overwriting a file that bypassed VFS says FILE_WRITTEN and still gets an identity`）；覆盖保留非空 Metadata（真实栈 `creating and overwriting keeps one identity, the metadata and the event follows real existence`，用测试已有 Repository 预置，不调用未交付的 setMetadata）；返回不额外 stat；同一路径两次写入共享 UUIDv7 |
| A03 父目录与拒绝 | 通过 | 真实栈 `missing parents are really created and never registered as nodes`（Node 数不增长）；替身 `every rejectable case is refused before a directory or a byte is created`（createDirectory / write 计数为零）；父路径物理文件拒绝且原样保留；缺建目录能力仅在父目录真缺失时拒绝 |
| A04 列表合并 | 通过 | 逻辑根列配置命名空间不碰后端；嵌套 Mount 同名遮蔽（真实栈）；深层虚拟祖先只列配置入口；物理文件遮蔽不列为文件；批量补 ID、零注册；子后端离线父层入口仍可见；父后端失败整体失败 |
| A05 事务与失败 | 通过（R1 修复后才成立） | 真实栈「文件已写 + 事件提交失败」→ STATE_ERROR + PARTIAL + 物理保留 + 无通知（按 ID 末尾标记确认）；真实栈「补父目录建到一半失败」→ 保留后端错误码 + PARTIAL + 盘上留着已建的第一层（`a parent creation that fails halfway says PARTIAL and leaves the directories it did create`）；core 补父目录三例：第一层成功第二层失败 → PARTIAL、首层失败 → NONE、建目录阶段 UNKNOWN 不降级；补完父目录写失败仍 PARTIAL；状态失败在任何写之前 → NONE |
| A06 串行与取消 | 通过（第二轮补强后成立） | **竞争已发生的直接证据**：真实栈 `the second write is held at the boundary before it touches the backend`——第一个写停在 Storage I/O 闩锁上时，第二个请求以 `CoroutineStart.UNDISPATCHED` 实际执行到第一个挂起点（即取锁处），断言它未完成且**后端调用日志长度没有增加**（一次 Storage 都没碰）；**最终结果层**：放行第一写后 `ALREADY_EXISTS`、`writeCalls == 1`、盘上内容仍为 first、Node 数 1，日志为 `stat → write → stat`。**取消的入口语义**：真实栈 `a write cancelled at the DefaultVfs entry propagates, releases the lock and commits nothing`——取消的异常在**调用协程内部**捕获到独立信号再检查，是 `CancellationException` 本身、不是 `VfsException`、原因与传入实例一致；随后同一边界可再取并完成一次真写入，Node / 事件 / 通知均为零（`DefaultVfsStageBoundaryTest` 三个用例是阶段拒绝与模块边界，不是并发证据） |
| A07 模块与阶段 | 通过 | `the four operations still to be delivered are refused with no side effect`；`the file operations live in core and reach into neither a storage engine nor the database`（源码检查：无 SQLDelight / OpenDAL import）；Registry 无事件回归 |
| A08 构建与交付 | 通过 | `./scripts/check` 全绿；分模块计数如上；本文档即证据整理 |

## 4. 变异自测对照

**开发方自测**（Lead 实跑；不是独立复核结论，复核方未复跑这些变异）。

| 变异 | 实际报警 |
| --- | --- |
| 去掉 write 前的实际类型确认（直接信 Intent） | core `A02 the mode matrix is enforced on the real existence of the target` |
| 预检挪到写之后 | core `A03 every rejectable case is refused before a directory or a byte is created` |
| 补父目录后写失败 effect 降回 NONE | core `A05 a write that fails after the parents were created keeps PARTIAL, never NONE` |
| 通知挪回事务回调内（T14 回归） | T14 `A03 a real commit failure publishes nothing` |
| 串行边界改为 no-op | T13 `A04 the registry queues behind an open transaction` |
| **补父目录的事实合并去掉**（`withKnownChanges` 直接原样返回，保留逐层建目录） | core `A05 a parent creation that fails halfway reports the directories it already created`（expected PARTIAL but was NONE）**且** 真实栈 `A05 a parent creation that fails halfway says PARTIAL and leaves the directories it did create`；core 218 例报 1、integration 32 例报 1，撤回变异后全绿 |
| **取锁去掉**（`write` 里 `boundary.withLock { … }` 改为直跑） | 真实栈 `A06 the second write is held at the boundary before it touches the backend`：日志长度 2 → 3，断言「第二个请求一次 Storage 都没碰」失败 |
| **取消被包装成 `VfsException`**（`write` 入口把 `CancellationException` 包成 `STORAGE_ERROR` 再抛） | 真实栈 `A06 a write cancelled at the DefaultVfs entry propagates, releases the lock and commits nothing`：捕获值变成 `VfsException: write cancelled`，「取消没有被包装成 VfsException」断言失败 |
