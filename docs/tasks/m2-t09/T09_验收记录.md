## 3. B 阶段变更内容

| 文件 | 变更 |
| --- | --- |
| `vfs/core/.../router/MountRouter.kt`（新增） | `MountRouter.of(namespaces, mounts)` 校验并快照；`route` / `isConfiguredDirectory` / `listConfiguredChildren` / `isMountPoint` / `hasDescendantMounts`；段前缀比较私有扩展 `startsWithSegments` |
| `vfs/core/.../router/MountRouter.kt`（同文件） | `RouteMatch(mount, relativePath)`：选中挂载 + 挂载内相对 `StoragePath` |

设计要点：

- 挂载集合与命名空间集合按值快照，外部修改入参不影响视图（A06）；不引入 Trie、缓存层或可插拔策略。
- 匹配是线性扫描 + 最长段前缀；命中不到返回 `null`，`MOUNT_NOT_FOUND` 由调用方按 T02 §3.2 判断（含虚拟目录），本组件不抛。
- 配置目录 = 逻辑根 + 命名空间根 + 挂载点 + 挂载祖先，构建期一次性算成「目录 → 直接子目录名」映射，查询不做字符串截取。
- 校验错误码：命名空间名格式非法 `INVALID_URI`；根挂载、重复位置、未配置命名空间下的挂载 `INVALID_ARGUMENT`。
- 未改动既有 `StoragePath`、`MountRecord`、Vfs 公共签名、Schema、scripts / CI。

## 8. 未验证事项与已知边界

- **纯逻辑验证**：A01～A06 证明逻辑路径无法经路由逃出挂载相对路径，**不代表已抵御真实文件系统的符号链接或外部并发替换**（T12）。
- **解析成功 ≠ 可访问**：`isConfiguredDirectory` / `listConfiguredChildren` 只描述配置结构，不证明后端存在该目录；stat / list 与后端条目合并属 T10 / T15。
- **`null` 的解释权在上层**：无匹配时需先判断虚拟目录再决定 `MOUNT_NOT_FOUND`，本组件不代替 T10 / T15 做该判断。
- **物理根重叠未检查**：`storageKey` 不透明，不同 key 不代表物理根不重叠，实际校验属 T12 / T18。
- **动态挂载未实现**：视图构建后固定，增删挂载需重建（T02 §3.1）。
- **名称含 `%` 的文件不可寻址**：A 阶段收紧的已知代价。
- 路由为线性扫描；无性能证据前不引入索引结构。
