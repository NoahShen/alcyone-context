### 机制层（非业务接线）

> 这组只用**真 SQLite 状态库 + 通知器**，**不涉及 Local FS**；业务层接线由上面的真栈 / 包装用例证明，两者不互相冒充。

| 机制 | 证据 | 层级 |
| --- | --- | --- |
| **真 COMMIT 失败**（主动关闭状态库让 COMMIT 真的失败） | `EventPipelineRealStackTest.A03 a real commit failure publishes nothing` | 真 SQLite + 通知器 |
| 提交前不通知 | `EventPipelineRealStackTest.A03 no consumer hears anything before the transaction commits` | 真 SQLite + 通知器 |
| 事务抛出不发布 | `EventPipelineRealStackTest.A03 a transaction that throws publishes nothing` | 真 SQLite + 通知器 |
| 追加冲突回滚同批 Node | `EventPipelineRealStackTest.A02 a rejected event id rolls back the node registered in the same transaction`（**真实主键冲突**） | 真 SQLite |
| Consumer 失败不回滚已提交 | `EventPipelineRealStackTest.A04 a failing consumer and a parked one do not change the committed result` | 真 SQLite + 通知器 |

**机制证据与业务接线证据分开**：`EventPipelineRealStackTest` 证明的是「COMMIT 失败 / 追加冲突时事务层的行为」，业务层（`DefaultVfs`）的接线由上面的真栈 / 包装用例证明；两者不互相冒充。

## 3. 本轮补的四个缺口

| # | 缺口 | 补证 |
| --- | --- | --- |
| 1 | `failOnStateWrite` 没有**业务层接线**证据 | 新增 `DefaultVfsStateWriteFailureRealStackTest`（真 SQLite + 真盘 + 状态写失败包装），覆盖写入 / 删除 / 文件移动 / 目录移动四类，各断 `STATE_ERROR` + 正确 effect + **本事务修改回滚（旧记录 / Metadata 保留、失败操作的成功事件未提交）** + 无成功通知 |
| 2 | 目录移动**后项超限**的整树 effect | `DefaultVfsDirectoryMoveTest.A04 a later file over the limit keeps the earlier copy and reports PARTIAL`：第一份确实复制成功、目标根已建，第二个文件超限 → `PARTIAL`（不是单文件读失败的 `NONE`） |
| 3 | T22 遗留的**两种长度事实** | `R2 a source file that really grows is caught by the recheck and is not deleted`（**真的**把源追加成 5 字节，直接断源 5 / 目标 3 / Metadata / 原 ID / 无成功事件）；`R2 a source whose recheck length is still unknown does not block the move`（当前长度仍 `null` 不阻碍） |
| 4 | 目录移动缺**「物理完成、COMMIT 前」**取消窗口 | `DefaultVfsDirectoryMoveRealStackTest.A06 a directory move cancelled before the commit propagates and rolls the paths back` |
