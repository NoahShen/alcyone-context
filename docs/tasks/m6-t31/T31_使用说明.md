## 1. 产物坐标与仓库配置

### 1.1 坐标清单
- Group: `com.github.noahshen.alcyone`
- Version: `0.1.0-SNAPSHOT`
- 模块与 Artifact ID 对照：
  - `:common` -> `alcyone-common`
  - `:vfs:api` -> `alcyone-vfs-api`
  - `:vfs:core` -> `alcyone-vfs-core`
  - `:vfs:storage` -> `alcyone-vfs-storage`
  - `:vfs:persistence` -> `alcyone-vfs-persistence`
  - `:vfs:runtime` -> `alcyone-vfs-runtime`

*注：根聚合工程与 `:integration-tests:vfs` 均不发布。*

### 1.2 本地仓库位置与清理
产物输出目录位于工程根目录下的：
```
.local/sdk-repository/
```
该目录已在根目录 `.gitignore` 中被忽略（位于 `/.local/` 下），绝不会发布到全局用户目录 `~/.m2`，也不进入 Git 版本追踪。

如需清理旧产物重新生成，可直接删除该目录：
```bash
rm -rf .local/sdk-repository
```

## 2. 常用操作命令

### 2.1 一键打包并运行消费工程验证（推荐）
```bash
./scripts/t31-consumer-check
```
该脚本会自动：
1. 删除旧的 `.local/sdk-repository/` 目录；
2. 执行 `./scripts/dev gradle publishMavenJavaPublicationToProjectLocalRepository` 将 6 个模块发布至项目内本地仓库；
3. 调用独立消费工程（`tools/validation/t31-consumer`）进行编译并运行，断言全部公开生命周期和正常重开。
4. 退出码为 0 表示验证完全成功。

### 2.2 仅执行本地发布
```bash
./scripts/dev gradle publishMavenJavaPublicationToProjectLocalRepository
```

### 2.3 仅运行独立消费工程验证
```bash
./tools/validation/t31-consumer/run-consumer.sh run
```

### 2.4 查看消费工程运行期 Classpath 解析
```bash
./tools/validation/t31-consumer/run-consumer.sh printClasspath
```
可观测到依赖全部解析自 Gradle 缓存与本地仓库生成的 snapshot jar，绝无源码项目或 classes 捷径。

## 3. 消费工程覆盖的公开流程与预期输出

消费工程代码位于 `tools/validation/t31-consumer/src/main/kotlin/com/github/noahshen/alcyone/validation/consumer/ConsumerMain.kt`。
主要覆盖两个阶段：

- **Phase 1（完整生命周期）**：
  1. `AlcyoneVfs.create(config)` 启动 Runtime；
  2. `subscribe` 注册事件监听；
  3. `write(..., WriteMode.CREATE_NEW)` 创建持久节点与临时节点，并接收 `FILE_CREATED` 事件；
  4. `read` 读回文件内容；
  5. `stat` 与 `list` 状态查询与目录列表核对；
  6. `setMetadata` 与 `getMetadata` 校验标签与描述；
  7. `openStream` 分块（4 字节 buffer）读取并在 use 块中完整关闭；
  8. `move` 移动文件，核验 Node ID 保持、Metadata 保持，且收到 `FILE_MOVED` 事件；
  9. `delete` 删除移动后的文件，核验再查询抛出 `NOT_FOUND`；
  10. `finally { vfs1.close() }` 完整关闭 Runtime。

- **Phase 2（正常重开一致性）**：
  1. 使用相同配置再次 `AlcyoneVfs.create(config)`；
  2. `stat` 校验第一阶段未删除的持久节点，断言 Node ID 完全相同；
  3. `getMetadata` 校验 Metadata 完全相同；
  4. `read` 校验内容字节完全相同；
  5. `finally { vfs2.close() }` 完整关闭 Runtime。
