## 4. 建议优化（不阻塞）

`opendalNativeClassifier()` 把所有非 Mac 系统归为 Linux、所有非 ARM 架构归为 x64。当前 scripts/dev 的平台白名单已限制正式入口，因此不是当前支持路径上的阻塞；以后扩大平台时建议改为显式映射并拒绝未知组合，避免错误 classifier 静默落入 classpath，不必现在引入公共平台解析框架。
