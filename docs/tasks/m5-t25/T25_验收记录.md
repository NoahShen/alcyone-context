## 3. 失败观察与实测记录

以下都是**观察到的**后端行为，写进实现与文档时如实标注来源：

| 现象 | 实测方式 | 处理 |
| --- | --- | --- |
| OpenDAL 0.50.6 webdav `capability.rename == true`，文件 rename 可用 | 真实服务探针（`A05 the capability table ...` 的真实原生移动） | `nativeFileMove = true`，Adapter 补「目标全新 / 父目录存在」预检 |
| rename 目录返回 `IsADirectory` | 历史探针来源待补；本轮 A05 只证明 Adapter 在 rename 前拒绝目录 | `nativeDirectoryMove = false`，目录走 Core 复制回退 |
| rename 会覆盖目标、会顺手建父目录 | 真实服务探针 | Adapter 预检目标不存在、父目录存在 |
| 只读共享（`readonly: true`）写请求服务端 403 | 真实只读共享（`A05` 只读用例） | 落 `STORAGE_ACCESS_DENIED`，不伪装成功 |
| 写响应丢失时 effect 是 `UNKNOWN` | 真实 HTTP 故障装置（`A06` 写响应丢失用例） | 直接断言 `UNKNOWN`，不降级 |

## 4. 未验证边界

- **不覆盖**：崩溃 / 断电恢复、自动重试 / 补偿、账号管理、广泛并发与关闭压力（T26 / T27 / E04 / E05）、跨平台实跑（T28）。
- **只对一种服务器**：WsgiDAV 4.3.3 + Cheroot 10.0.1；其他 WebDAV 服务器未验。
