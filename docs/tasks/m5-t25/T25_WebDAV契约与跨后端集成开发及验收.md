## 1. 目标与边界

补齐 WebDAV Storage 已承诺的操作语义，通过公开 Runtime 验证 Local FS ↔ WebDAV 文件和目录移动。沿用 T24 的真实测试服务、配置和身份规则，Core 继续只依赖 Storage Port，数据库事务只包含状态与事件写入。

例：把 `/resources/local/report.txt` 移到 `/resources/remote/report.txt`，内容、Node ID 和 Metadata 保留，成功后源文件消失，持久化一条 FILE_MOVED。

T24 的公开 move 已可进入 Core 复制回退，本任务不是重新实现移动编排。网络超时、自动重试 / 补偿、崩溃恢复、账号管理和广泛并发压力测试不在本轮范围；T27 承接并发与生命周期专项，不能据此跳过本轮新增资源路径的基本清理验证。

## 2. 开发内容

### 2.1 补齐操作契约

整理 stat / 单层 list / 建目录 / 有界读写 / 删除的已有证据，补三种写入模式、文件与目录类型冲突、空目录和非递归删除等缺口。Storage 不自动补父目录，公开 VFS 按既定规则补齐；预检不能被描述成对外部并发的原子保障。

例：CREATE_NEW 遇到已有目标应拒绝且保留原内容；REPLACE_EXISTING 遇到缺失目标应拒绝。中文、空格及 `+` 名称验证实际落点，继续禁止路径段中的 `%`，不重新设计 URI 规则。

### 2.2 接通 WebDAV 流式读取

实现 WebDAV `readStream` 并经公开 `openStream` 验证，复用现有 reader 所有权和 native 生命周期机制，不先重写整个 Local FS Adapter。按实际读出字节限制总量，覆盖空文件、零长度读取、恰好上限和超限；`null` 上限遵循现有无界契约。

例：对超过默认 ByteArray 读取限额的文件分块计算摘要，证明公开流可完整读取；指定较小上限则报 LIMIT_EXCEEDED。正常关闭结果、失败清理、重复关闭及 Runtime 回收遗忘流均须释放资源，完整移除 Runtime 跟踪以关闭返回结果为入口。

### 2.3 核实原生移动与能力声明

根据当前 OpenDAL 与测试服务实测决定原生文件移动是否可接通，支持时遵守目标全新、源存在及目标父目录存在的 Port 语义；不支持时诚实声明并保留 Core 复制回退。原生目录移动不强求，不能把后端原生能力不足解释为公开 move 一律不可用，也不能仅凭历史 T04 探针宣称当前支持。

例：同一 WebDAV Mount 的文件移动可走经验证的原生路径或复制回退，交付注明实际策略；跨 Mount 仍走复制删除。服务端账号拒绝写入不等于适配器能在初始化时自动识别只读，不新增网络权限预检或 ACL。

### 2.4 验证跨后端文件与目录移动

Local FS → WebDAV 与 WebDAV → Local FS 都验证文件和目录正例，目录含空目录、已登记后代及未登记文件；复用 T21 / T22 编排，不增加第二套身份迁移逻辑。核对原 ID、Metadata、registeredAt、内容及源删除，目录只发一条根级 DIRECTORY_MOVED，不批量登记原先未登记的后代。

例：移动 `notes/`（含 `empty/` 与已登记的 `a.txt`），目标保留空目录，`a.txt` 身份不变。选一个代表用真 SQLite 查询事件字段并正常重开比对身份，无需对每种组合重复完整重开矩阵。

### 2.5 失败报告与删除顺序

复用 T23 状态提交失败证据，重点补远端写入部分完成后失败、目标确认失败、删源失败等接线；分别核对物理文件、Node / Metadata、持久事件和异常。复制确认前不删源，失败不自动清理残留或回移；保留后端 code / cause / UNKNOWN，只把已知有变化时的 NONE 合并为 PARTIAL。

例：目标只写入部分字节后连接断开，源保持完整且不调用源删除，原路径映射不迁移、无成功移动事件；如果无法确定远端变化则保留 UNKNOWN。能力拒绝可用替身，网络结果丢失至少有真实 HTTP 故障证据，不能全部靠在 Storage 返回前抛错代替。

### 2.6 测试服务、清理与证据边界

沿用 `./scripts/webdav-check` 和独立 source set，补真实只读服务拒绝写入或等价的服务端权限反例；必要故障装置继续只监听 loopback，临时文件和连接在失败时也清理。区分真实服务、故障包装、替身与源码审查，事件表证明持久化，异步订阅证明通知，两者不混用。

例：测试装置主动断开响应后可以验证 UNKNOWN，但不证明任意静默服务器都会及时返回。用户已接受请求 / close 无最长耗时保证，协程取消也不等于中断 native；取消用例用可控交接点并先结束在途工作再关库，不留下无期限等待的故障服务。

## 4. 验收标准

| 编号 | 必须满足 | 直接证据 |
| --- | --- | --- |
| A01 基础契约 | 读写 / stat / list / 建目录 / 删除符合 Port；三种写模式、类型与父目录边界明确 | 真实服务正常与反例，核对内容和列表；可引用已有用例，不复制矩阵 |
| A02 流式读取 | 公开远端流按实际字节计限，无界读取可超过 ByteArray 默认限额 | 分块摘要、空文件 / 零长度 / 边界限额；不可仅信 stat 长度或整文件读入再包装流 |
| A03 文件移动 | 同 WebDAV Mount 及 Local FS ↔ WebDAV 成功，目标不覆盖，ID / Metadata 保留 | 真实内容与源消失、旧 ID 指向新路径；说明原生或回退路径，补目标已存在反例 |
| A04 目录移动 | 双向保留空目录和登记子树，沿用整树确认后删源及根级事件规则 | 真实目录树、已登记后代与未登记文件；代表用例真库查事件及正常重开 |
| A05 能力与权限 | 能力声明符合实测，不支持能力明确拒绝；远端拒写不伪装成成功 | 当前能力表、真实服务权限反例；机制层能力不足测试可复用并标层级 |
| A06 失败事实 | 部分写入 / 确认 / 删源失败不误提交；UNKNOWN 不降级，已知变化不报 NONE | 至少一条真实 HTTP 结果丢失证据，其余可受控注入；直接断言物理 / 状态 / 持久事件 / code / effect |
| A07 资源与取消 | 新增流路径正常、失败与遗忘回收均清理；不取消宿主或提前关库 | 公开流关闭与同库重开；所有权 / 取消接线定向证据可结合 T12 / T18 复用，不声称强制中断 native |
| A08 回归与交付 | 两套检查实际通过，无服务缺失静默跳过，能力与限制如实记录 | 735 / 11 基线分别统计，源码与 XML 差异解释、实际平台、提交号及未验证项 |

不规定新增测试数或变异次数；关键断言应直接对应事实，时序测试用可控信号，不靠延时猜测。只有复用机制而未验证 WebDAV 接线的条目不能标成真实远端通过；变异记录注明执行人、变更及报警用例，不把历史结果归为本轮执行。
