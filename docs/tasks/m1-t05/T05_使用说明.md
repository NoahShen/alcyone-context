## 准备与构建

在 macOS arm64 安装系统自带的 bash、curl、tar、unzip、shasum 后，从仓库运行：

```sh
./scripts/dev bootstrap
./scripts/dev gradle --version
./scripts/dev gradle clean build --console=plain
```

也可以从父目录运行 `./alcyone-context/scripts/dev gradle -q projects --console=plain`。`projects` 报告以 QUIET 级别输出，本项目需加 `-q` 才输出模块树。入口自行定位仓库，只对子进程设置环境；不要直接调用系统 Gradle，也不要手动改变系统 Java。

`bootstrap` 下载固定的 Temurin 21.0.12.1+1 和 Gradle 8.14.3，来源与 SHA-256 固定在 `scripts/dev`，校验后才解压。再次执行会校验归档和安装文件并复用；损坏时明确失败，按错误提示删除对应归档或安装目录后重试，不回退到系统工具。

JDK 在 `.local/jdk/`，发行包在 `.local/gradle-dist/`，Wrapper 发行包、依赖及 Daemon 状态在 `.local/gradle-user-home/`，临时文件在 `.local/tmp/`。这些目录和各模块 `build/` 都被 Git 忽略；首次 Wrapper 运行会在独立缓存下载并按 Wrapper properties 中的 SHA-256 校验发行包。

## 日志与诊断

```sh
mkdir -p .local/tmp/acceptance
./scripts/dev gradle clean build --info --console=plain > .local/tmp/acceptance/build.log 2>&1
./scripts/dev gradle -q javaToolchains
./scripts/dev gradle --stop
```

完整自测记录见 [T05 验收记录](T05_验收记录.md)，本机原始证据位于 `.local/tmp/acceptance/`，不会随 Git 提交。`--version` 的 Kotlin 行是 Gradle 内置 DSL 版本；项目 Kotlin 编译器版本以 `gradle/libs.versions.toml` 与编译诊断为准。

## 剩余限制

当前只有六模块构建骨架，无公共 API、Port、Schema 或业务测试，`test NO-SOURCE` 不代表 SDK 测试通过。SQLDelight 插件及 SQLite Driver 已配置，数据库声明留 T11；OpenDAL native 固定为 `osx-aarch_64`，其他 OS / CPU 尚未验证，入口和 Adapter 构建配置会明确拒绝。

集成测试模块已配置 kotlin-test / JUnit 5；根构建为所有 Test 任务选择项目 JDK 21。发布、CI、完整 SDK 和平台扩展由后续任务承担，T04 独立工程保留且未并入构建。
